# AI 设置后台实施记录

2026-10-06。用户要求：资料管理测试正常，私有后台不再需要新闻审核，准备 AI 后台。当前为本地实现与部署准备；服务器未升级到本阶段，未执行实际百炼问答。

后续服务器证据：用户已提供新镜像 16 项离线测试通过、完整数据备份成功、app/admin healthy 及 init/inspect 的 applied 输出。初始化时已确认用量保留（4 次、37,858 Token），未执行后台收费测试；本记录保留开发阶段历史。

## 实现

- 私有后台仅显示资料管理与 AI 设置。移除 `/api/articles`、`/api/assets/.../withdraw` 等新闻审核管理接口及后台 capture/image 工作线程。保留管理员登录、Origin/CSRF、会话过期和失败锁定。前台新闻、采集、自动正文、已发布内容和图片继续运行，原新闻及审核数据不删除。
- `ai_config.py` 在既有管理库中扩展不可变配置版本、目标/加载状态、心跳、显式测试任务。资料目录及版本不重新导入。显式 init 采纳原环境配置，重复运行不覆盖后续修改。
- 使用固定版本 cryptography 的 Fernet，加密 Key 与历史版本。主密钥来自独立只读挂载文件；生成工具拒绝覆盖且不输出密钥。数据库及密钥分别备份，AI 启用标记防止丢库后回退旧环境配置。
- 后台维护启停、Key 替换、业务空间、知识问答服务 ID、超时、并发、访客/IP/全站每日次数、Token 预算与预留量。字段与范围严格验证，固定错误信息，不回显输入密钥或校验异常原文；GET 仅返回已配置状态。
- 草稿不影响访客；应用后公开进程每秒同步并写回加载版本、兼容版本、心跳及脱敏状态。后台每 2 秒刷新，目标通常 2 秒内加载；状态区区分实际加载、等待、失败与离线，不将入库视为生效，也不将生效视为云端验证。
- 保持长生命周期 AIService，原子替换配置/客户端，请求捕获不可变快照并在结果提交时使用原会话版本。启停及切换不终止已开始的回答；删除/过期仍拒绝晚回答。一次性启动恢复与日常更新分开，不重置 active、次数、Token 或在途预留。
- 连接或启停改变会话兼容版本，额度/超时变更保持会话。管理员可主动使旧会话失效，以配合控制台内部知识库/提示词变更。回退上一确认版本生成新修订。
- 显式付费确认后，admin 只写测试任务，公开进程以固定短问题执行。测试共享访客用量账本和并发，草稿额度不能扩大当前预算。每小时最多 3 次、滚动 24 小时 10 次，同时最多一个后台测试任务。失败保留预留，无自动重试/自动应用；重启取消此前队列或在途测试。
- 常规保存、查看、轮询及健康检查均不调用百炼。前台 status 轮询仅调用本站，启停状态可刷新；会话版本过期明确提示开始新对话。
- 部署包采用白名单，配套密钥生成、环境显式采纳、脱敏 inspect 和私有旧环境片段导出，Compose 密钥挂载需用户合并，保持原环境与数据卷。

## 验证

- 全套离线 pytest 140 项通过（27.92 秒），一条现有 Starlette/httpx 弃用警告。新闻审核旧 HTTP 用例改为退役接口验证及原新闻/图片/备份兼容验证，保留权限与存储测试。
- 16 项新增 AI 配置/生命周期测试全部通过；补充每秒检查主密钥缺失/错误状态后，该套再次 16 项通过（8.28 秒）。包含未登录/CSRF/Origin、密钥不回显和存储加密、空 Key 保留、坏输入脱敏、修订冲突、草稿不生效、额度与会话兼容、启停/重启、兼容版本 ACK、错密钥保留旧运行配置、回退、测试共用额度/并发、失败不重试、取消旧测试、CLI 不输出密钥、丢库不回退环境、在途回答与首次从停用启用。
- 后台三份脚本及前台 ai-ui.js 通过 Node 语法检查；HTML ID 无重复、脚本引用齐全、session 监听先于登录流程、已无新闻审核区域。没有执行真实浏览器视觉验收或 Docker/Linux 镜像验证。
- 所有测试使用临时库和假 Key，并禁止真实 provider 调用。依赖安装因沙箱网络限制获准在外部执行；Windows 测试临时目录限制同样通过已授权的外部 pytest 运行解决。

资料管理已经由用户确认线上正常，本阶段的 AI 后台准备不能写成线上成功。实际部署、独立主密钥安装、运行状态及用户页面操作仍须按部署说明核对。本站 Token 记账是调用限制，不能充当云账单金额硬限额。
