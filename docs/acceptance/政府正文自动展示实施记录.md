# 政府正文自动展示实施记录

日期：2026-10-06。用户取消政府正文逐篇审批，改为自动取回后展示；图片仍独立许可、本机保存，其他机构/企业仍原文入口。AI不实现，Git由用户处理。

主app在COLLECT_ENABLED=1且GOVERNMENT_FULLTEXT_AUTO=1时启动自动任务，不依赖管理员账号或admin服务。只处理已启用的NASA/CNSA/CMSE已登记新闻；队列总20，自动15，保留5个手动槽位；每轮最多入队5，单任务完成后间隔60秒。按采集元数据哈希识别首次/更新，失败24小时冷却、每哈希最多3次，抓取不在公开请求中运行。

自动发布前验证正文结构、全部文本覆盖、原始语言和来源署名；特殊结构或未覆盖文字拒绝标完整全文。发布原文新版本并保留原ID/首次入库时间，不改历史回填队列；撤回/拒绝/已有人工许可全文不自动覆盖。旧私有草稿保存在不可变版本中，但不会当作自动抓取的原文发布。正文版本更新时旧图片不混入新版本。

明确区分展示策略与授权：自动版本publication_mode=government_direct、completeness=structure_checked，permissions.text仍pending，公开usage.status=operator_direct，不制造人工审批或版权授权凭据。已向用户说明CMSE官网文字复制需书面许可；政府身份不使所有原创报道、转载稿和图片自动进入公有领域。具体条款见部署文档中的官方链接。

9项自动专项覆盖：无需账户发布、真实许可状态不伪造、关闭策略降级、撤回与已有全文保护、失败冷却、非政府不扩源/私有稿不直接发布、增量正文更新保留ID、严格覆盖/特殊结构、队列预留、原语言/作者、旧私人稿保留。完整回归79项通过；专项9项在最终语言/署名修正后再次通过。

Standards审核发现2项P2：保存时重写时间导致图片所需草稿/发布哈希不一致，以及自动任务占满人工图片队列。已修为发布刚保存的规范草稿，并限制自动任务最多15；测试覆盖。Spec未发现确定性新增缺陷。既有服务端认证和图片保存测试保留。

未决：国内服务器升级、真实站点正文覆盖与访问限制、自动任务实际运行进度、浏览器显示以及图片/数据库联合恢复需用户验收。本轮不宣称全部政府历史全文已抓完，也不宣称版权许可已取得。
