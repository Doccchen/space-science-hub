# 新闻来源展示策略改进记录

日期：2026-10-06。依据更新后的《新闻阅读页与许可分层实施方案》。本轮不实现AI和图片，Git仍由用户提交。服务器在国内，升级与国内浏览器最终确认待用户执行。

## 当前行为

人工清单独立于agency/company及地区分类：NASA、国家航天局、中国载人航天为government_candidate，其他已知和未知来源默认link_only。候选身份不等于许可；仅逐篇正文许可有效、完整性核对通过的全文版本返回full_text。未核对、旧guide、其他机构及公司都只提供元数据/原文链接。撤回、拒绝或过期政府版本返回unavailable。

列表、详情、content三接口执行同一策略。link_only的summary为空，正文/图片为空，不输出私存旧内容；content保留original_url。列表可读政府摘要从当前许可正文提取，绝不使用历史来源节选。来源策略哈希加入content_version，修改策略会使打开中的弹窗重新核对。数据库v4、文章ID、首次入库时间、采集与队列不需要新迁移或删除。

可读政府标题/阅读正文按钮打开弹窗；其他标题直接到原站，不渲染摘要占位、不显示重复标题详情按钮。旧ESA/企业站内hash链接留在新闻列表并提示原文入口，不自动访问外站。政府不可用旧链接可说明原因。弹窗内更新政策后，列表行同时替换，焦点回退到新标题。

保留三篇逐稿核对的NASA正文（Flight Directors 13段、Christina Koch 9段、DAVINCI 5段）；原中文Model Wing导读留作历史文件/数据库版本，不进入新发布包或Docker镜像，不公开展示。CNSA/CMSE未新增许可样本，不宣称已获得其全部全文授权。现有访问阻塞与历史归档例外不变。

## 验证

61项回归通过，新增覆盖：ESA及五家企业即使有已审核旧全文也不能公开；政府候选必须逐稿许可；未知来源默认链接；策略变化使版本失效而历史恢复不丢。既有采集、分页、许可撤回、备份恢复和资料下载测试通过。前端JavaScript语法检查通过。

本机浏览器：政府全文显示13段；Esc关闭前后滚动位置同为1812px，焦点回原新闻标题。旧ESA直达地址关闭弹窗并在列表显示原文入口。ESA列表无摘要段落/正文按钮，标题为外站链接；旧Model Wing导读不显示。Standards和Spec复核均未发现新可操作缺陷。

新版部署脚本维持一致性备份、同卷重建与失败镜像回滚，额外遍历其他机构/公司来源，检查三接口link_only边界。样本验收仅按至少三篇可用政府全文判断；缺失或撤回仍报告incomplete，不隐式重发。下载28项与24封面继续本机验证，不请求OSS。

限制：服务器脚本未执行前不宣称云端验收通过；原站访问因地区限制失败也不会自动搬运其正文。AI内部上下文服务和图片采集/存储均未实现。
