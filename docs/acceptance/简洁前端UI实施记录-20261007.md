# 简洁前端 UI 实施记录

2026-10-07。用户已确认依据成熟产品参考与公网复查优化 UI，AI 回答排版稍后处理。本阶段为前端修改与部署准备，未修改服务器、后台、知识库、计费、新闻采集或下载数据。

后续部署反馈（2026-10-07）：用户明确确认“已经部署”。记录为用户侧完成发布；没有提供新的浏览器验收或脚本日志，本轮不声称 Agent 已独立完成线上视觉验收。

## 设计与范围

采用保留品牌的局部调整：继续星知航标志、浅蓝/深蓝配色和统一中文字体，背景改为浅色纯底，控件使用 8–12px 圆角，降低重复容器、渐变与阴影。页面标题约 25–28px、主导航约 64px，新闻与资料直接进入内容。设计取值：视觉变化 3、动画 1、信息密度 7、素材依赖 3、品牌保真 9。参考与理由见前端 UI 审查报告，沿用已确认方向，不新增未经支持的搜索、排序或问答能力。

新增 `quiet-ui.css` 作为明确的任务布局层，避免大范围重写已有阅读弹窗与回答样式。AI message、正文 Markdown、依据折叠、轮次、请求去重、实际模型调用均保留。AI 输入仍位于历史之后，持续对话布局与回答排版留到后续；本轮主要精简提问前的欢迎区。

## 变化

- 公共导航改为“航天新闻 / AI 问答 / 资料下载”；新闻页缩短大口号，去掉三页英文装饰行和重复跨页宣传模块。关于页保留服务说明，组件参考链接留在设计文档。
- 新闻保留左侧筛选和小屏折叠，来源先列出公共机构或小组前几项，其余按需展开；已选来源保持可见。未启用的历史来源仍可筛选，不删来源。重置、地区筛选和分页快照继续沿用。
- 新闻列表以细线分隔，元信息保留来源、日期与原文语言，机构类型/发布主体地区/历史状态放到来源详情。本站全文的标题打开既有阅读弹窗，保留原文入口；外链稿只保留标题外链，移除重复原文按钮，不编造摘要。
- 当前默认筛选不再重复显示“当前结果：全部”。更新状态、每页条数和指定页跳转按需展开；来源采集异常仍在更新状态入口显著提示，读取失败/保留上一结果提示继续存在。
- 资料桌面保持网格，封面高度降到约 160px；小屏书目变为 72×108px 缩略封面和文字/下载的单行结构。作者、分类、PDF 格式与真实大小保留，不重新引入介绍或详情弹窗。下载链接仍指向原稳定 ID 入口。
- 封面加载中显示加载占位；加载成功隐藏占位，缺失/错误显示简洁 PDF 占位，不重复长书名，也不误报“暂无封面”。
- AI 状态读取失败立即禁用提问；停用/配置未就绪时隐藏示例、显示真实服务提示，防止仍指引发送。服务恢复后示例与提问自动恢复，未发送的输入不清除。示例只填入输入，不自动发送；保留已有两个知识范围已知的固体发动机示例，不擅自扩展问题覆盖声明。

## 发布

通过 `tools/package_frontend.py` 生成 `space-frontend-release.tar.gz`、SHA256、清单和 `upgrade_frontend.sh`。白名单包含 13 个前端文件及 manifest，index 最后替换，脚本备份源目录与运行容器文件、构建持久镜像、原容器热更新并检查 HTTP 字节与 API。失败恢复原源文件、运行文件与镜像标签；不重启容器，不修改 Compose/环境/数据卷或后台文件。

部署后用户需检查新闻筛选/更多来源/原文及全文、打开关闭后分页保持、资料搜索/分类/分页与下载入口、AI 停用及启用空态。无需发送问答来验证本轮 UI。更新方式与现有热更新一致，按部署说明执行。
