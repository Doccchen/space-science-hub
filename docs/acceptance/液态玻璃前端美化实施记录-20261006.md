# 液态玻璃前端美化实施记录

日期：2026-10-06。范围：本地新闻与资料页面前端美化。

用户请求为参考设计方案美化网页；方案作为设计参考，其中规划阶段的“不修改功能代码”和后续部署、提交、推送流程不作为本轮执行指令。本轮未部署、提交或推送。

## 实现

- 使用独立 `web/glass-theme.css` 和 `web/glass-theme.js`，在新闻与资料页启用浅冰蓝主题；主导航位置与切换行为保留，科普演示页保留原有背景。
- 新闻筛选重组为类别分段、来源/条件地区/刷新、更新时间与结果范围；复用既有筛选状态、请求参数和 DOM ID。
- 顶部仅结果总量与每页 10/20/50 条，下方唯一主分页；沿用 API 页数、当前页邻近页码、省略号与快照。桌面跳转默认展开，小屏跳转默认收起；单页与空结果隐藏主分页，避免第 1/0 页。
- 翻页成功滚动到结果栏并聚焦结果栏；失败保留成功页状态。翻页加载时禁用操作。
- 白底新闻卡片、来源元信息、阅读标识与动作；阅读弹窗正文继续使用不透明白底，行宽约 720px。许可、hash、滚动恢复及阅读版本逻辑未改动。
- 资料工具条、白底书籍卡片、原封面 contain、胶囊下载按钮。四列/三列/两列及窄屏单列由 CSS 调整；保持原搜索、分类、请求取消、封面回退和下载 URL。
- 两页提供同步的“减少透明效果”复选项，本机保存，初次使用跟随系统偏好。滤镜不支持时实色降级；减少动态偏好取消位移反馈。无新增外部字体、依赖、壁纸或图片请求。
