# 人工审核与服务器图片实施记录

日期：2026-10-06。用户先提出人工审核和OSS新闻图片，后明确改为服务器保存并直接加载；以最后选择为准。新闻图片的OSS代码/配置/SDK依赖已从交付中移除，PDF下载保持。单管理员；政府候选逐篇许可；其他来源原文阅读；AI未实施。未提交或推送Git。

## 已实现

- 后台独立服务与目录，只有服务器loopback端口，通过SSH转发登录。服务器交互初始化账号，无默认密码；慢哈希、1小时会话、登录失败锁定、HttpOnly/SameSite、Origin/CSRF与请求体上限。
- 新闻关联私有草稿、版本冲突保护、人工许可/完整性确认、原子发布、撤回和审核记录。切换文章或保存时继续编辑会中止发布，不能把A的确认用于B。
- 受控主机/路径、DNS公网校验后固定连接IP并保留TLS主机校验；robots校验、请求/字节/时间预算。抓取只生成私有pending草稿，不自动授权，不开任意URL接口。
- 图片逐张核对许可、用途、署名、图注、本文关系和当前位置；与已发布草稿版本绑定。只允许JPEG/PNG/WebP、每张8MiB/2400万像素、每版本最多5张；后台单队列执行，磁盘保留256MiB余量。
- 图片原始字节保存在命名卷/data/news-images，原子落盘后登记。图片不挂静态目录，每次请求检查来源策略、当前正文版本及正文/图片许可；直接FileResponse且no-store，撤回入口404。新正文版本不展示旧图，前端有图注/credit、延迟加载和失败提示。
- 数据库v5附加账户、会话、草稿、任务、图片、日志；迁移前一致性备份。容器重启未完成任务标失败，需人工重试，不隐式重发。
- 升级脚本暂停后台和采集，SQLite＋引用图联合快照与SHA256清单；只恢复到空目录，原卷保留。数据和文件一起恢复，不只备份SQLite。
