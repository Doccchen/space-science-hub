# 杂志前端实施记录

2026-10-07。用户确认将修改后的航天科技杂志效果稿用于正式前端。阶段：本地实现与发布准备完成；尚未上传服务器，不代表线上部署或浏览器独立验收。

## 设计与范围

正式前端采用「航天科技杂志 + 沉浸新闻首屏」：暖白底 `#f3f1ea`、深蓝文字 `#10233f`、橙色封面点缀 `#e66a35`。正文交互强调色采用较深的橙褐 `#a33d18`，避免浅橙色小字难读。中文标题使用本地黑体，栏目标注采用等宽字，新闻编号使用少量衬线数字。8px 基础间距，结构直边，控件 4px 圆角；少量悬停过渡，系统减少动态偏好停用动效。

保留现有星知航标志、三个栏目、新闻筛选与页码分页、来源状态、阅读弹窗、AI 服务状态/额度/对话/依据逻辑和资料稳定下载 URL。没有修改后台、采集、知识库、PDF、云配置或服务器。

新增 `web/editorial.css` 为最后加载的主题层，覆盖原浅蓝主题；旧层保留当前交互结构及媒体/阅读基础样式。`web/index.html` 加入历史影像封面与栏目层级，不引入效果稿的主题切换面板、假数据或模拟回答。现有其他任务的前端/后端修改不被重置。

## 页面变化

- 新闻：约 620px 的桌面影像首屏，叠加左下标题与真实 NASA 原文；下方暖白目录、筛选和编号新闻行。保留缩略图署名、来源详情、无图/加载失败行为、原文和全文入口。跨栏目入口回到新闻页下方。
- AI：知识工作台式标题、真实状态栏与较宽输入区，例题仅填入；未启用时隐藏鼓励提问的大标题。已有回答结构只统一配色和容器，不重写模型结果或来源。
- 资料：桌面四列真实封面目录，手机两列；极窄屏单列。作者、分类、格式、大小、下载与分页继续显示；缺封面仍为 PDF 占位，不加入已取消的介绍弹窗。
- 阅读：正文与弹窗改为暖白/深蓝；滚动、关闭返回和焦点合同保留。

主视觉 `web/earthrise.jpg` 为 NASA 官方地出历史照片（1968-12-24），署名 NASA，并链接[官方原文](https://www.nasa.gov/image-article/apollo-8-astronaut-bill-anders-captures-earthrise/)。原文件地址：https://www.nasa.gov/wp-content/uploads/2023/03/apollo_8_earthrise_1968_as08-14-2383.jpg 。图片尺寸 1600×1250，约 67 KB。该素材属于网站历史影像封面，不接入新闻采集或改变 APOD 排除策略。照片加载失败时仍有深色实底、可读标题及原文链接。
