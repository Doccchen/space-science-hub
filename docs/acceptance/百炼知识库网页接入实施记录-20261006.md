# 百炼知识库网页接入实施记录

日期：2026-10-06。授权：正式接入网页，AI 前端统一为已上线新闻与资料页的冰蓝玻璃风格；服务器操作全部由用户执行，不继续 Agent 收费验证。

## 实现

新增 `backend/bailian.py` 处理已确认的知识问答 SSE；严格生成结束、HTTP/业务错误、断流、超时、数据/答案长度上限，无 POST 自动重试；只保留生成阶段正文与安全来源元数据，最终用量不累加中间快照。

新增 `backend/ai.py` 提供 status、创建/删除会话、ask；独立 `ai.sqlite3`，不更改新闻数据库。原子预留额度和会话处理中状态，UUID 请求去重，Cookie owner 隔离，过期/版本变更/新对话禁止旧回答入库。失败与未知用量保留 token 预留量。AI 禁用/配置错误不阻止新闻服务启动。

将 home 固定示例替换为真实问答布局，`studio.js` 仅保留共享导航；`ai-ui.js` 单独管理状态、来源、新对话与晚响应。前端 DOM 安全 Markdown 子集，无 innerHTML、动态代码执行、模型图片/链接操作；没有引入外部依赖。`ai.css` 使用现有主题参数，减少透明偏好扩展至三页。

首轮实际样本没有逐条引用标记，因此采用“本次检索资料”；页码显示原始“返回位置”。不展示私有链接和片段全文，不承诺逐结论证据检查。无有效来源返回资料不足，不凭模型文字推断拒答分类。

## 验证与界限

本地全套 pytest（新闻、资料、阅读、管理、自动全文、AI、探测与发布工具等）109 项通过，耗时约 15 秒；保留一条现有 Starlette/httpx 弃用警告。新增 AI 离线测试包括请求去重、上下文、两访客隔离、清空、过期、轮次/并发/预算、重启额度、失败不重试、旧响应拒绝与用量保留、跨来源、无依据、SSE 完整/断流/业务错误、来源/密钥/链接过滤；部署工具测试只管理 app 环境并拒绝未知结构和越界 tar 成员。

前端 JS 语法、Bash 升级脚本语法、发布包成员与逐文件 SHA256 校验、Compose 增量补丁的幂等性均通过。发布包约 21 KB，不携带私钥/环境配置/数据库/预览文件；启动与 HTTP 基础检查在正式服务器上仍待用户执行。

Codex 内置浏览器使用仅绑定 127.0.0.1:8094 的离线预览：明确标注固定测试响应，发送、Markdown 卡片、来源展开及新对话正常；所查看页面控制台未见 error/warn。截图保存在 `artifacts/ai-preview/home-after.png` 与 `chat-after.png`。预览模块不进入 AI 发布包，并在 Docker/完整阅读包中排除。

未进行 Agent 实际收费调用、远程部署、正式网页实际问答、多尺寸自动验收、Firefox/Safari/实际 Chrome/Edge 验收、移动性能测试或精确事实评测。用户提供的首轮服务器 API 成功与本地离线 UI 测试分开记录，不混作实际网页验收。

部署包、密钥隐藏配置与带回退的用户操作脚本见《百炼知识库网页正式接入部署》。升级脚本不问答，只核对启用状态与已有功能；真实网页使用由用户在上线后决定。
