# 知航画廊：品牌与构图

本轮是局部扩展，其余页面沿用既有编辑式品牌。Logo 为 `web/brand.svg`（深色观看界面使用亮度反转），字体沿用既有中文宋体展示字、微软雅黑正文、Consolas 索引。

深蓝 `#10233f` 作观看空间、纸白 `#f3f1ea` 作文字、橙色 `#e66a35` 作当前索引；来自现有 editorial.css。真实摄影来自 `web/gallery/`，完整溯源及权利记录为 `web/gallery-slides.json`。未引入外部图标库或字体。

标题承担叙事，照片保留完整构图。桌面晚霞首图右侧放标题；喷焰细节图改左侧，避免遮挡发动机。手机照片与标题分层，功能入口始终可达。查看模式去掉标题干扰，保留退出和出处。

本地界面截图见 `artifacts/gallery-verification/desktop.png` 与 `mobile.png`；新闻双栏固定样例截图 `news-reader.png` 仅为回归证据。

## 2026-10-12 螺旋展廊扩展

当前首页采用左侧标题、右侧 CSS 3D 螺旋展位；手机标题下置。12 张影像完整顺序和实施说明见 `docs/plans/螺旋阶梯展廊实施记录-20261012.md`。当前展位正面展示完整照片，橙色边框标识停驻点。相邻层提供深度，隐藏背向的展位，避免遮挡和不可见焦点。手机正常空间界面截图为 `artifacts/gallery-verification/mobile-spiral.png`，`mobile.png` 为减少运动的静态版本。

## 后续：全屏沉浸版（当前）

当前版本已改为居中主图、全视口空间与按需界面，去掉常驻标题和橙色展位边框。手机展位采用主体焦点的纵向取景，完整图模式仍展示整幅照片。色彩环境来自当前照片的模糊延展，知航品牌、导航与素材出处保留在可唤出的界面中。详见 `docs/plans/沉浸式展廊界面与探索改进-20261012.md`。

### 配色协调（当前）

按用户要求，欢迎页、展廊和菜单统一引用 design-system.css 的共享角色：米白 ui-surface、深蓝 ui-on-surface、橙色 ui-primary，辅助文字用 ui-muted。Logo 使用原始蓝橙版本，取消白色反转。照片环境只作低透明度色彩延展，取消深色遮罩与亮度压低；实际展示照片不加滤镜。键盘焦点与当前索引使用和其它页面一致的橙色。欢迎截图为 `artifacts/gallery-verification/welcome.png`，桌面和手机截图同时更新。

### 横向画廊试用（当前）

当前首页为单张全屏横向影像画廊，取消空间场景，采用纯米白观看表面。切换为轻微横移和交叉淡入，展开索引提供缩略图。欢迎、控件和图片内容沿用既有品牌规范。实施记录见 `docs/plans/横向影像画廊试用记录-20261012.md`。

### 石墨灰 / 雾白试用（当前）

经用户同意预览，欢迎、影像与影像菜单使用石墨灰 #191B1F、柔白 #F2F3F4 和铜橙 #C77B52；新闻、问答和资源页使用雾白 #F2F3F4、深灰 #262A30。浅色界面采用同色系的深铜橙 #975332，保证小字号链接与白色按钮文字的对比度。Logo 仅基于原始 SVG 调色，几何保持：brand-gallery.svg 为深背景版本，brand-neutral.svg 为浅背景版本；原 brand.svg 保留。照片不加滤镜，横向画廊与所有现有交互保持。当前仅本地预览，未上线。
