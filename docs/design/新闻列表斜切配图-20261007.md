# 新闻列表斜切配图

2026-10-07。用户提供带红框的列表截图，要求右侧图片填充成大块区域，并减少页面两侧留白。属于现有杂志前端的局部视觉调整。

桌面新闻页最大宽度由1440px提升至1840px，左右内边距48px；刊头和页脚同步对齐。新闻筛选与各栏目功能不变。

有图新闻行采用「编号 / 文字 / 280–440px宽图片区」布局，图片区域与整行同高、最小260px。图片填满右侧，左缘用 clip-path 形成27%斜切；署名和许可放在图片区右下方的深色实底文字区，完整可读且不受斜切影响。文字不叠在图上。

无图保持原文字列表；图片加载失败时移除整个图片区域并恢复文字布局。小于600px时图片移至文字下方，斜切变浅，避免窄屏标题被压缩；极窄屏图片区最小190px。图像原始文件与后台许可策略不变，仅调整网页展示裁切，不改变原文或下载源。

增加 news-thumbnail-media 包裹图片，用于裁切，figcaption 单独保留。现有DOM检查继续验证失败恢复、署名/许可、来源筛选、10条分页、AI状态与资料下载URL。

离线预览可使用 `tools/capture_news_preview.py` 获取20条公开页面新闻样本和已有署名配图，仅保存到忽略目录 `artifacts/magazine-preview`。`package_magazine_preview.py` 将配图嵌入本地预览，不将公开快照加入正式网站或Git，也不操作生产数据。预览图片来自该新闻已有配图，不使用无关航天图片替代。

本轮未执行服务器更新。响应式规则已写入，未据代码检查声称完成多尺寸浏览器验收。
