# 新闻阅读入口与链接优化

日期：2026-10-23。状态：已完成本地代码修改、服务器部署及公网验证，详见 `../deployment/新闻阅读优化部署-20261023.md`。

## 已实施的修改

| Before | After | Why |
| --- | --- | --- |
| 文末大框中的“查找相关论文”小链接 | 仅在标题信息下方保留一个“搜索相关论文”实色按钮，删除文末重复区域；桌面左右布局，手机纵向布局，点击高度至少 44px | 方便读者发现和点击，避免重复 |
| 显示自动转载说明及“图片请到原文查看。” | 全文阅读时移除这两类说明，保留署名、发布方原文入口；无正文时保留必要的不可用状态说明 | 清理用户明确不需要的提示，避免空白区域 |
| 显示“如何核验这条信息”入口 | 从新闻阅读弹窗中移除 | 按用户要求简化页面 |
| 正文中的完整网址为纯文本 | HTTP/HTTPS 网址自动可点击，处理句末标点与配对括号 | 减少复制地址的操作 |
| 采集时只提取链接文字 | 同时保存文字范围及原始链接目标，覆盖段落、标题、列表和表格；相对路径基于来源页面解析 | 保留原文的跳转能力，不猜测地址 |
| 新闻链接继承弹窗的小字号 | 正文链接继承所在段落、列表或单元格字号 | 保持阅读清晰 |

论文按钮沿用 `/assets/research.html?news=文章ID`，保留新闻上下文。其目标为本站研究助手，因此没有附加外链箭头或虚构检索平台。

正文外链在新标签页打开，并设置 `noopener noreferrer`。正文仍使用 DOM API 构建；不解释来源 HTML，不支持危险链接协议。Markdown 相对链接也使用来源页面作为基准，代码块与行内代码中的网址不自动转换。

## 修改位置

- `web/news-reader.js`：论文按钮、指定提示及核验入口删除、来源地址传递。
- `web/article-renderer.js`：纯文本网址识别、结构化链接、Markdown 相对链接。
- `web/article.css`：按钮布局、移动端排列、正文链接字号。
- `web/styles/pages.css`：通过 `tools/build_styles.py` 从源样式重建。
- `web/index.html`、`web/guides.html`、`web/research.html`：更新脚本或样式缓存版本。
- `backend/review_capture.py`：保留原文文字链接与目标地址。
- `backend/reading.py`：兼容旧正文格式，校验新增链接位置、范围及地址。
- `tests/test_news_links.py`、`tests/test_news_reader_links.cjs`：链接采集、发布及浏览器回归检查。
- `tests/test_guides.cjs`：适配核验入口删除和论文按钮新增后的断言。

新增链接字段为可选的 `links` 数组，`start` / `end` 按 Unicode 字符计数，`url` 为绝对 HTTP/HTTPS 地址；列表项增加 `item`，表格单元格增加 `row`、`column`。原有正文和段落编号继续兼容。

## 限制与上线说明

- 已部署到服务器；没有批量重写历史正文。公网真实新闻验证通过，新闻数量 475，配置保持不变。
- 已有新闻中的纯文本网址在使用新版本渲染器时即可点击。
- 历史采集版本如果只保存了链接文字、没有保存真实目标地址，无法从文字可靠恢复链接。此类文字链接需要重新采集或从保留的原始资料重建；本次未批量覆盖历史正文。新采集内容会保留链接目标。
- 浏览器使用本地固定样例，外部目标页面由测试拦截，验证了链接地址与打开行为，没有验证外部网站服务可用性。
- Impeccable 上下文加载器因引擎未安装且缓存目录不可写未运行；本次直接读取项目规则、设计技能资料与现有组件完成局部调整。
