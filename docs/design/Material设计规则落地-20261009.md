# 知航共享界面规则

在现有杂志主题上引入 Material 3 的语义配色、操作层级和反馈状态。保留米白背景、深蓝文字、橙色强调、新闻影像、图书堆叠及问答背景插画。

## 实施

- 新增 `web/design-system.css`，由首页与独立资源导航页最后加载。共享颜色角色、标签/正文/说明字号、控件圆角和反馈时长。
- 发送问题采用主要实心按钮；新对话、刷新、分页采用次要描边按钮；重置采用文字操作。禁用状态使用独立配色。
- 新闻与资源导航添加可移除的已选条件标签。类别选中增加勾选标记；资源页保留现有内容和布局。
- AI 输入区在服务可用时显示快捷键提示，发送中更新按钮文字与 aria-busy。按用户最新要求，撤回新增的禁用原因说明、输入区错误强化和服务重查按钮；服务未开放及网络失败沿用原有逻辑。
- 阅读工具栏采用容器底色，手机阅读弹窗接近全屏，保留关闭、焦点恢复和正文滚动逻辑。
- 通用前端打包脚本新增共享 CSS。旧动效打包脚本仍从旧预览生成文件，本轮发布应使用当前 web 文件，不能重新生成旧预览覆盖本次改动。

## 本地验证

运行 `node tools/check_design_system.cjs`：AI 与新闻脚本及资源页内联脚本语法通过；两页共享 CSS 引用各一次；六组文字颜色对比度均超过 4.5:1（主按钮 6.25、正文 13.93、说明 5.47、选中 12.41、错误 7.00、禁用 4.75）。对比度结果仅针对所检查的颜色组合。

模拟状态接口失败及重新进入页面后成功，验证原有禁用和恢复输入流程；共两次状态请求，无问答调用。`git diff --check` 通过。

本轮未进行浏览器视觉/响应式验收。后续用户已授权并完成服务器发布，见[部署记录](../deployment/共享界面规则部署-20261009.md)。首页基于最新线上文件合并，避免覆盖并行修改。
