# NASA 图片库 robots 修复

实测同一 User-Agent：官方图片库 /robots.txt 返回 403，349 的 JPEG 返回 200。旧代码在 robots 请求就停止，尚未请求图片。

依据 [RFC 9309 2.3.1.3](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1.3)，robots 的 4xx 可视为 unavailable 并继续获取资源。新代码仍在 robots 429、5xx、网络故障或明确 Disallow 时停止；正文/图片自身 403 仍拒绝。现有版权核对和主机、路径、公网 DNS、下载大小规则不变。

4 项 HTTP 回归与 13 项配图回归通过。本机已核对真实图片 HTTP 200，生产服务器保存仍需单条 retry 验证。

## 服务器更新

选择没有正在生成的 AI 回答时操作。本补丁仅包含请求代码、回归测试和本文，无数据库迁移。

```bash
set -e
cd /root
sha256sum -c space-thumbnail-robots-fix-20261007.sha256
cd /opt/space-news
backup="/root/thumbnail-robots-before-$(date +%Y%m%d-%H%M%S)"
mkdir -m 700 "$backup"
old_app=$(docker compose ps -q app)
test -n "$old_app"
docker inspect "$old_app" --format '{{.Image}}' > "$backup/app-image.txt"
cp backend/publisher_fetch.py "$backup/publisher_fetch.py"
tar -xzf /root/space-thumbnail-robots-fix-20261007.tar.gz
docker compose build app
docker run --rm --mount type=bind,src=/opt/space-news/tests,dst=/app/tests,readonly space-news-app python -m unittest discover -s tests -p test_publisher_fetch.py -v
docker compose --profile review up -d --no-build --force-recreate app admin
docker compose --profile review ps
```

两个容器 healthy 后执行：

```bash
docker compose exec app python tools/news_thumbnail_manage.py retry --article-id 349
docker compose exec app python tools/news_thumbnail_manage.py status
```

ready 表示服务器保存成功，刷新网页查看右侧图片。若仍失败，提供返回的错误代码；生产出口与本机可能不同。保持自动采集关闭直到此条展示确认。350、352 状态不会自动更新，需另行 inspect/retry。
