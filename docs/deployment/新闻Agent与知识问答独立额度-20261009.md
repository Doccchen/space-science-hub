# 新闻 Agent 与知识问答独立额度

2026-10-09，用户明确要求两服务按各自计费场景独立设置，不再共用站内访客/IP限额、并发和Token约束。已完成实现、历史迁移、后台入口与服务器发布；未调用任何模型，新闻问答和MCP仍关闭。

## 后台操作

刷新并登录私有后台，左侧现在有两个入口：

- **AI 设置**：普通知识库问答的连接、额度和测试，原配置保留。
- **新闻 Agent**：新闻专用超时、并发、访客/IP每日次数、全站每日次数、Token用量约束和预留量。先“保存新闻额度草稿”，再“应用新闻额度草稿”，等待已加载版本与目标一致。

新闻页有独立草稿、版本历史、运行心跳和今日用量；修改普通问答不会修改新闻额度，反之亦然。额度应用不替换密钥、不改变新闻开关、不自动测试百炼。云端真实计费由对应服务账单确认，本后台不把两类产品的Token或请求折算成同一种人民币费用，也不是云账单金额硬上限。

## 数据及运行隔离

普通服务仍用 `/data/ai.sqlite3`；新闻使用 `/data/news-agent-usage.sqlite3`。各自的预算对象、并发计数、访客/IP/分钟计数及每日统计独立。代码复用通用账本实现，但配置、数据和运行计数不共享。新闻额度版本存于独立 `news_limits_versions/news_limits_state` 表，不改 `ai_config_state`。

新闻参数每秒由公开服务加载，应用超时后保留has_thoughts请求和可信检索来源提取。配额变化不重发收费任务或清空历史会话。已初始化新闻用量库/表丢失时停止新闻服务而不是重建空账本，其他网站功能继续运行。

原文未完整读取、尚未启动上游模型的新增新闻任务明确记0模型Token；已经开始请求但未取得用量时仍保留预留量，不猜测远端是否收费。请求次数仍包含失败请求，避免失败路径绕过访问限额。
