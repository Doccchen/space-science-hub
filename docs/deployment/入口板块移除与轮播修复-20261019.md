# 移除首页入口板块与轮播图片修复 · 2026-10-19

用户要求移除首页三张功能入口卡片，并反馈部分轮播图片不能显示。已移除板块及专用样式，顶部导航继续提供论文查找、知识问答和资源导航。

## 排查证据

按 diagnosing-bugs 流程检查实际页面内嵌的 12 张轮播数据。初始逐张 HTTP 检查均为 200，Pillow 能完整解码，说明未发现缺失或损坏的图片文件。浏览器点击阿波罗 11 号时，等待窗口内仍停留上一张且 aria-busy=true，随后最终显示；原图约 2.3 MB。检查还发现一次图片加载失败会永久禁用该图的切换按钮，直到刷新。回归测试先复现并断言失败：A transient image failure must remain manually retryable（true !== false）。

## 修复

- 原有历史图片生成 1800/960 尺寸 WebP，七张蓝箭图片使用已有 WebP 展示版本；保留原图作备用，不裁切、补绘或改变署名/来源。
- 12 张桌面主展示资源合计从 9,075,145 字节降至 2,317,678 字节，约减少 74%。
- 按屏幕宽度选择图片；预加载下一张，单次加载 7 秒后尝试备用来源；一次失败不永久禁用手动选择。
- 保留当前有效图片直至下一张成功，所有备用源失败后可手动重试；保持图片、标题、署名和许可对应。
- 保留快速切换的请求版本校验、离页取消、悬停/键盘焦点暂停和减少动态效果逻辑。
- 回归测试直接使用实际内嵌的 12 张数据，静态 JSON 目录与之同步，避免只测试旧五张样本。
- 热发布工具支持新增图片目录及新文件的回退，发布前核对历史更新都在镜像中。
