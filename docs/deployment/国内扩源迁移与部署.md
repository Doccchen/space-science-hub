# 国内扩源迁移与部署

本地实现已完成，用户负责Git提交及服务器执行。本文件替代重复首次部署流程；不修改公网8080配置、不删除卷。

## 升级

本机上传新版包：

```powershell
scp -i "D:\Documents\竞赛\AI+信息素养\GPT.pem" "D:\Documents\竞赛\AI+信息素养\GPT-WebSite\artifacts\packages\space-news-domestic-release.tar.gz" root@8.137.164.100:/root/
```

服务器执行（先归档原代码/配置，保留现有.env）：

```bash
set -e
tar -czf "/root/space-news-code-before-domestic-$(date -u +%Y%m%dT%H%M%SZ).tar.gz" -C /opt space-news
tar -xzf /root/space-news-domestic-release.tar.gz -C /opt/space-news
cd /opt/space-news
bash tools/upgrade_domestic.sh
```

脚本一致性备份当前数据库并保存旧记录身份，构建镜像，临时停用采集调度后升级。运行全部固定测试；逐源使用真实robots、列表和三篇详情进行探测，全部成功才启用。失败源保留禁用并保存错误。随后检查真实增量、相同内容去重、类别/来源API分页、模拟连接失败保留历史、独立备份恢复与容器重建，最后恢复每小时调度。

结果位于domestic-upgrade-UTC时间目录。脚本可能只成功启用部分来源，result.json列出实际成功列表和未启用来源；这不等于四源全部验收。最终docker compose ps应为healthy且仍绑定0.0.0.0:8080。容器重建后首次启动探测可能尚未healthy，等一轮检查再看。

脚本错误时保留现场并尝试恢复调度，不自动还原数据库。单源探测失败不清库、不修改网站路径配置绕过错误；查看该源probe-error.log后再处理。

## 迁移规则

启动时共用进程间锁，再执行可重复的增量迁移。v1已有新闻时自动创建/data/news.sqlite3.before-v2.sqlite3一致性备份。增加来源collector_kind/region/publisher_kind/enabled/last_result/retry_after_at；新闻summary_kind/content_source/published_precision/published_raw/published_origin；独立回填任务及URL队列表。

NASA/ESA回填国际机构并保留启用；新增国内四源默认禁用，之后启用状态存数据库，不在每次启动重置。禁用只停止采集，历史仍可读取。

不删除表、不重建文章ID、保留URL和first_seen_at。旧摘要为空回填summary_kind=none；其余为source_summary。旧发布日期有值为second，空值为missing，日期出处为feed且原始日期字符串未知。v1把全部语言默认写en而没有验证（已有西班牙文新闻），因此旧en记录回填und，避免全部标成英语；新中文适配器显式zh，RSS使用来源声明的语言，缺失为und。

所有日精度国内日期按北京时间解释，2025-10-01内部排序值为2025-09-30T16:00:00+00:00。前端日精度固定按北京时间显示日期，不显示补出的00:00。详情缺日期保持缺失，不取列表或正文事件日期代替。

## 历史回填

历史任务不放入Web启动流程。每个任务结束时间固定为初次运行时间，之后用run_id恢复。任务与迁移、采集共用锁；任务正在运行时定时轮次跳过，下一轮继续更新。

首先小批验证（例如国家航天局）：

```bash
docker compose exec -T app python -m backend.backfill --source cnsa --since 2025-10-01 --max-pages 2 --max-articles 10 --max-seconds 90
```

输出id为断点标识，status可能为paused_budget，这是正常批次暂停，并非历史已完成。恢复：

```bash
docker compose exec -T app python -m backend.backfill --source cnsa --resume 上次输出的id
```

解析器修复后需要重新检查undated条目时，在原任务恢复命令添加--retry-undated；仅本批首次显式重排队，无需重复新建任务或删除检查点。普通resume会跳过已判undated条目。

批量包装器每批最多5个列表页（包含首页检查）、50次详情、240秒，默认最多10批；重复同命令沿用已保存run_id：

```bash
bash tools/backfill_domestic.sh cnsa 10
bash tools/backfill_domestic.sh cmse 10
bash tools/backfill_domestic.sh cas_space 10
bash tools/backfill_domestic.sh landspace 10
```

逐源串行执行，不并行启动四个回填命令；某源paused_error/paused_throttle后暂停处理，不阻塞继续验证其他来源。回填命令显式source可用于未启用来源验证，但不会自动启用该源。

--dry-run执行预算内的真实读取/解析但不插入新闻或回填任务；初始化数据库兼容字段仍会执行。

回填遍历当前官网可枚举的全部审核栏目页，逐条按详情发布日期筛选，不因一条早于起始日期的置顶新闻停止。每个URL先入队，失败轮转重试，时间中断保持pending。续跑重扫上一分页边界；总页数变化从首页重扫，靠URL去重防止重复。

状态enumerated_complete表示当前可枚举栏目区间已遍历且无失败/无日期缺口，不保证网站已撤下文章的全量历史。enumerated_with_gaps必须核对失败和无日期队列，不报完整覆盖。若官网在相同总页数下重排旧页超过一个分页跨度，断点重扫可能无法保证全量，应新建第二轮任务交叉核对URL集合。回填报告与来源last_success_at分离，历史任务成功不冒充最新列表更新。

包装器日志在backfill-evidence/来源下。2025-10-01含当天，2025-09-30排除；缺日期只进入undated队列，不计已确认范围，也不将采集时间回写成历史日期。

## 回退与恢复

升级脚本保存.env备份、旧镜像ID、旧记录身份与一致性数据库备份。新增结构保持旧代码可读，因此优先代码回退；恢复前数据库备份会丢失升级后新增新闻，不能当作日常代码回退。

代码回退时先保留当前数据库一致性副本，再还原原代码归档，使用domestic-upgrade目录保存的previous-image-id.txt将原镜像重新标记为space-news-app:latest，运行docker compose up -d --no-build --force-recreate。不得执行down -v。旧程序只调度NASA/ESA；新增历史仍在数据库，旧界面不具备新分组能力。

灾难恢复应在停写状态恢复数据库，先保存当前库和WAL/SHM现场，再使用SQLite backup恢复一致性副本；需要另行决定如何保留升级后数据。验收脚本仅在独立restore-check.sqlite3测试恢复，绝不覆盖在线数据库。
