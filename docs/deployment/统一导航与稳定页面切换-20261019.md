# 统一导航与稳定页面切换 · 2026-10-19

按用户截图统一顶部导航，并取消页面切换时自动定位到标题栏下方的行为。

## 改动

- 新闻、论文查找、资源导航使用同一 header 结构、原始品牌标志、字标、字号、桌面 96px / 手机 116px 高度与导航间距，右侧统一显示“关于本站”。
- 选中状态由链接自身的固定下划线表示，取消移动下划线定位脚本，固定链接占位，避免选中样式影响导航排布。
- 使用 scrollbar-gutter: stable，避免长短页面切换时滚动条出现/消失引起横向偏移。
- 主站页面逻辑地址改为 #page/news、#page/home、#page/about，不再与正文 main 的 id 同名。点击使用 History API，不触发浏览器锚点滚动；旧 #news/#home/#about/#library 链接继续识别并归一化。
- showPage 不再自动滚动；移除整页 translateY 入场及新闻大标题切换位移。书架导航直接跳转目标页，不先展示隐藏的旧资料页。
- 保留新闻弹窗关闭时回到原阅读位置、问答提交后的答案定位、图片轮播与书架交互。
- 同步问答和资源页面的初次加载条件、欢迎逻辑，兼容新逻辑地址，避免问答页面等待下一次轮询才初始化。
- 主站同页导航保留 Ctrl/Command 等修饰键新标签打开行为；浏览器前进/后退仍由原路由处理。
