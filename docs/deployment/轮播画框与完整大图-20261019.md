# 轮播画框与完整大图 · 2026-10-19

用户确认“收窄画框＋分类适配”方案，以减少大面积边缘空白，同时保留必要的完整构图。

## 实施

- 桌面画框居中，最大 1280px，并按可用视口高度约束宽度，固定 16:10 比例；移动端保持固定比例。切换图片不改变画框高度。
- 常见横图采用 cover 并沿用主体位置；竖图、示意图、方图和过宽全景图采用 contain，避免强行放大裁掉主体。留白区域采用站点浅色。
- 图片点击或键盘激活可打开原比例大图弹窗，提供原始图片链接。打开时停止切换并取消未完成的切换请求，关闭后恢复滚动、焦点和自动轮播；离开新闻页时自动关闭弹窗。
- 不增加图片介绍、遮罩或画面文字，保留出处和许可。

## 验证与发布

轮播备用源/超时/异步竞态及弹窗打开关闭、暂停和焦点恢复回归通过；图片分类、图录一致性、导航和问答状态回归通过。

线上检查：测试台横图和晚霞横图为 cover，阿波罗 11 号竖图为 contain；三次测得画框均约 806.4×504px，高度一致，图片正常解码。完整大图弹窗图片为 contain；关闭后 body overflow 恢复，焦点返回 cover-open。
