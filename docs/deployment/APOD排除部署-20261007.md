- 不进行数据库架构迁移；使用每个新闻连接注册的确定性 SQL 函数与一致的 Python 判定。
- 145 项离线 pytest 通过（29.64 秒），一条现有依赖弃用警告；前端状态回归通过。新增 5 项验证标题/链接形式、普通 NASA/ESA 保留、新采集与手动入库、历史分页/计数、直达接口及旧队列无网络抓取。生产未部署。

## 服务器升级

后端需要重启 app，选择没有正在生成的 AI 问答时执行。同一终端按步骤运行：

```bash
set -e
cd /root
sha256sum -c space-apod-exclusion-20261007.sha256
cd /opt/space-news
backup="/root/apod-before-$(date +%Y%m%d-%H%M%S)"
mkdir -m 700 "$backup"
old_app=$(docker compose ps -q app)
test -n "$old_app"
docker inspect "$old_app" --format '{{.Image}}' > "$backup/app-image.txt"
tar -czf "$backup/backend-before.tar.gz" backend
tar -xzf /root/space-apod-exclusion-20261007.tar.gz
docker compose build app
docker run --rm --mount type=bind,src=/opt/space-news/tests,dst=/app/tests,readonly space-news-app python -m unittest discover -s tests -p test_apod_policy.py -v
```

上述测试只用临时库，没有真实网络采集或模型调用。构建与离线测试成功后，再停服并备份原数据卷：

```bash
docker compose --profile review stop app admin
mkdir "$backup/data"
docker cp "$old_app:/data/." "$backup/data/"
docker compose --profile review up -d --no-build --force-recreate app admin
docker compose --profile review ps
```

app/admin 重新使用一致的镜像，原 `.env`、主密钥挂载、账号与共享卷不变；不要删除卷或重新初始化目录/AI。
