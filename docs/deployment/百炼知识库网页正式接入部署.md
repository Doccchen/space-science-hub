## 2. 配置密钥（服务器）

先确认控制台 API 示例仍是已验证的业务空间与已发布服务，再执行：

```bash
python3 /root/configure_ai.py
```

API Key 隐藏输入，不显示在命令行、输出或历史中；已有 Key 时可留空沿用。配置脚本只修改 `.env` 中 AI 相关字段，保留原值与其他配置，备份 `.env.before-ai-UTC时间`；两者权限 600。不要把 `.env`、备份或密钥发到聊天或 Git。

默认启用 AI，调用已验证 workspace/agent；并发 2，单问题 1500 字符，单对话最多 5 轮、历史约 1 小时、历史总字符上限 16000，供应商总超时 60 秒。模型与知识库本身的行为沿用百炼发布配置。

预算默认：每访客每分钟 4 次、每天 20 次；每连接 IP 每天 30 次；全站每天 100 次；全站每日 token 控制阈值 200000，每次调用前预留 20000。最终有用量则用实际总量结算，无最终用量/断流/取消保留预留量。额度按北京时间自然日累计，数据库持久保存，重启不清零。

这些是小规模首版的网站请求限制，不是供应商账单的金额硬上限。单次工具调用可能超过预留量，超时/失败也可能收费；应同时在云平台确认实际服务计费与账户预算。仅持久记录请求/状态/用量/平台请求ID，不保存 API Key 或上游规划文本。

目前公开入口为 HTTP，Cookie Secure 默认为 0；启用 HTTPS 后将 `AI_COOKIE_SECURE=1` 并重建 app。HTTP 不能保护访客问题与会话在传输中的机密性，所以页面提示不输入个人隐私或敏感资料。API Key 始终仅在服务器。

## 3. 发布（服务器）

```bash
cd /opt/space-news
bash -n /root/upgrade_ai.sh && bash /root/upgrade_ai.sh
```

升级会：

1. 验证差量包成员与逐文件 SHA256，检查 app/environment 的现有 Compose 结构；未知结构停止。
2. 在 `ai-upgrade-UTC时间` 保存源代码、Compose、运行容器的 web、环境设置、旧镜像与卷名，以及一致性新闻 SQLite 备份和旧新闻身份、资料数量；已有 AI SQLite 也单独备份。
3. 安装差量代码，只补充 app.environment AI 字段，构建新 app 镜像；在隔离临时目录使用 MockTransport/FakeClient 跑 AI 离线测试，不调用供应商。
4. 重建 app，等待 healthy，确认沿用原数据卷、旧新闻身份保留、资料数量不变、前端文件校验一致、AI status 已启用。管理容器不重建。
5. 失败尝试恢复之前的源代码/Compose/环境与镜像，保留当前数据；若原容器曾热更新前端，恢复该运行时 web 备份，避免回到过早的主题。回退不会删除新增未引用的代码文件或任何数据库。

成功标志：`AI website upgrade passed`，JSON 中 `ai_enabled=true`、`frontend_hashes=passed`、`paid_test_calls=0`。这仅表示网站代码部署、配置和基础检查成功，不代替用户实际网页问答验收。

备份包含密钥配置、新闻和可能的 AI 会话数据，只留服务器私有目录，不发送或提交。若自动回退失败，保留失败日志、目录名与当前容器状态，再确定手动恢复动作，不套用其他轮次的镜像/数据库。

## 4. 浏览器使用

打开 http://8.137.164.100:8080/#home ，Ctrl+F5。

界面采用与新闻/资料一致的浅冰蓝背景、玻璃操作面板、白底回答、圆角与蓝色胶囊按钮。初始推荐问题只填入输入框，不自动调用；点击发送或 Ctrl/⌘+Enter 才触发真实付费问答。输入未启用/配置错误时明确禁用，不使用固定答案代替。

支持独立会话、追问、新对话、来源展开、等待/失败/资料不足/限流提示。新对话清除本站旧历史，停止前端等待；已发送百炼请求不保证停止收费。旧请求晚返回不能进入新会话。问题和历史只由后端构造，客户端不能提交任意 endpoint、模型、历史或系统指令；不按 session_id 调用。

来源仅展示实际返回且有正文的记录名称与原始定位；不公开内部 ID、原始工具返回、知识库片段全文或私有/签名 URL。没有合格来源时不放行模型无证据事实回答，而返回资料不足提示。来源存在仍不保证具体结论正确，控制台知识库优先与拒答配置仍须维护。

格式采用安全的段落、标题、列表、粗体与代码 DOM 渲染，不执行原始 HTML，不自动打开模型链接，不预加载 PDF。公式文本保留原文；本版未引入公式排版库。

会话绑定不可预测匿名 Cookie 和服务端 owner，Cookie HttpOnly/SameSite=Strict，拒绝浏览器跨来源操作。IP 从真实连接 peer 读取，不自行信任访客 X-Forwarded-For。匿名 Cookie 可清除，因此 IP 和全站额度共同兜底。未来反向代理需明确可信代理及原始 IP，不能直接放开所有代理头。

会话过期后立即拒绝访问；每分钟及会话操作清理历史/缓存答案（最多约额外 1 分钟），请求用量元数据保留约 30 天。新对话删除对应历史与缓存答案，不删除费用记录或供应商侧留存。网页刷新不从本地存储恢复聊天内容，页面内切换新闻/资料则保留当前对话。

若要暂时停用 AI，在 `.env` 设置 `AI_ENABLED=0`，执行 `docker compose up -d --no-build --no-deps app`；新闻、阅读与资料保持可用。不要使用 `down -v`。
