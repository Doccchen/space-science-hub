# NASA 与 ESA 新闻缩略图

2026-10-07。本轮只给 NASA/ESA 新闻列表增加可选配图，不处理资料 PDF、来源 logo、AI 回答排版或 ESA 全文转载。包含上一轮 APOD 排除，历史 APOD 不展示、不再抓取正文或配图。

## 图片处理与使用依据

列表采用左文右图：桌面约 144×96px，手机约 88×60px，图片无效或缺失时保持纯文字。图片存入私有持久卷，通过受控缩略图接口返回；原始外站图片 URL 不直接交给浏览器热链。

每张图片独立记录完整署名及使用依据，支持 NASA 媒体指南、ESA 标准教育/信息用途条款，以及图像所在 figure 明确的 CC BY-SA 3.0 IGO。ESA 文本仍为原文链接；图片可用不代表正文也可转载。

自动流程只处理 figure 或已知媒体区域中明确的单独 NASA/ESA 自有署名。跳过 APOD、缺失署名、联合/第三方署名、Courtesy、Copyright、图库标记、logo/insignia 等标识、未知或相冲突的许可说明。OpenGraph 图片或来源名称不足以自动确认使用依据。图像页面结构不支持或来源不能访问时，条目仍可正常阅读。

这是保守的自动候选规则，不是对图像权利归属的法律保证；发布用途限当前教育/信息类站点，仍应抽查署名和用途。NASA 政策见[官方媒体指南](https://www.nasa.gov/nasa-brand-center/images-and-media/)，ESA 见[版权说明](https://www.esa.int/About_Us/Law_at_ESA/Intellectual_Property_Rights/ESA_copyright_notice)。CC 图片标注许可链接，缩略处理说明可展开查看。

缓存为最大 640×480 的 JPEG，等比例缩小、按 EXIF 调整方向，不裁切画面或删除画面内的署名。原始获取上限 8MiB、2400万像素，只接受 JPEG/PNG/WebP；不跟随未批准主机，不访问非公网解析地址，不绕过 robots、验证码、登录或地域限制。

后台采集开关默认关闭，每轮最多 3 条、每轮后等待 60 秒；同一版本失败最多 3 次、间隔至少 6 小时。已准备的图片不重复下载，撤回图片不会因文章元数据更新自动重新公开。未确认项可经人工核对后通过服务器工具登记，不重新恢复新闻审核后台。

## 本地验证边界

全套离线 pytest 153 项通过，随后补充许可/说明边界后，图片与 APOD 定向 13 项再次通过。图片测试用自制图及模拟网络；验证 ESA 图片与正文权限独立、署名/许可、失效/撤回、版本 URL、APOD/国内源排除、采集冷却和图片备份。Node 回归验证纯文字原文入口、可选图片、加载失败、读取新状态撤回图片后没有残留空白栏。

本机按真实下载器检查 NASA/ESA 示例页面时，DNS 解析返回非公网地址，按规则停止；没有绕过限制或下载真实图片。服务器采集能力、真实页面覆盖率和视觉效果未验收，不承诺所有 NASA/ESA 条目都能自动配图。

## 先验证少量真实采集

容器 healthy 后，先主动检查 3 条：

```bash
docker compose exec app python tools/news_thumbnail_manage.py collect --limit 3
docker compose exec app python tools/news_thumbnail_manage.py status
```

collect 会访问原新闻站及候选图片，但不调用百炼。ready 表示有符合规则并已保存的图片；unconfirmed 表示候选署名/依据未确认；failed 表示网络、robots、路径、格式或存储等失败，不尝试绕过。刷新前台时，有 ready 图片的对应条目才显示缩略图，其他保持纯文字。

自动采集默认为关闭。确认服务器正常后，在 Compose 的 app environment 增加：

```yaml
      NEWS_THUMBNAILS_ENABLED: ${NEWS_THUMBNAILS_ENABLED:-0}
```

在原 `.env` 中增加 `NEWS_THUMBNAILS_ENABLED=1`，然后只重建 app：

```bash
docker compose config --quiet
docker compose up -d --no-build --no-deps app
```

开关还受 COLLECT_ENABLED 控制；停止常规采集时也不会启动自动图片采集。无人为输入任意 URL 的公网抓取接口。

## 人工确认、撤回与恢复

自动流程无法识别合法署名时，可先核对具体图片权利归属、允许本站用途和许可。以 ESA 自有图为例，以下占位内容必须替换为已确认的真实条目 ID、图片地址及完整署名：

```bash
docker compose exec app python tools/news_thumbnail_manage.py register --article-id 123 --image-url 'https://www.esa.int/var/esa/storage/images/已确认的图片.jpg' --credit 'ESA' --rights-kind esa_standard --rights-reviewed
```

NASA 自有图使用 nasa_guidelines，图上明确 CC BY-SA 3.0 IGO 使用 cc_by_sa_3_igo。不能把任意第三方图标成 NASA/ESA 自有素材，不能仅凭文章来源传入这个确认标记。工具只允许对应来源已审核主机和图片路径。

撤回单图：

```bash
docker compose exec app python tools/news_thumbnail_manage.py withdraw --article-id 123
```

撤回后新的缩略图请求返回 404，前台读取新数据后移除图片。已在用户设备显示/缓存的图无法追回；文件仍私有保留。重新确认登记可恢复。

已有 `backup_review.py` 一致性快照已扩展为包含数据库引用的缩略图文件；完整站点备份仍需管理库、AI 库及独立主密钥分别按原文档保管。代码回退使用备份及原镜像，不删除新表/图片，不用旧数据覆盖后续新增新闻。
