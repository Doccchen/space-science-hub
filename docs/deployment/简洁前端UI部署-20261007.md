## 服务器执行

```bash
cd /root
sha256sum -c space-frontend-release.sha256
bash -n upgrade_frontend.sh
bash /root/upgrade_frontend.sh
```

脚本固定在原 `/opt/space-news` 项目操作。校验包与白名单，备份服务器 web 与当前运行容器的 web，构建镜像，再将前端素材更新到原 app，index 最后替换。进行资产字节/SHA256、新闻分页、资料 API 及 AI status 检查，不调用百炼问答。容器 ID 应保持不变，不需要停服、改 Compose 或挂载密钥。

失败会尝试恢复源文件、运行容器文件与原镜像标签，证据位于 `/opt/space-news/frontend-upgrade-时间/`。不要省略脚本而直接向运行容器解压，因为那样无法保证后续重建仍保留更新。

## 浏览器检查

使用 Ctrl+F5 强制刷新，确认标题和导航更简短。检查：

1. 新闻更多来源可展开，选择后仍可见；停用来源的历史新闻仍可筛选。每页条数在列表设置中，指定页跳转默认折叠。来源异常仍有提示。
2. 原文稿标题打开原文；本站全文标题打开原阅读弹窗，关闭后保持原页及筛选。
3. 资料仍显示原目录；桌面缩小封面，手机为紧凑书目行；搜索、分类、上一页/下一页和稳定下载入口正常。加载中的占位与真正缺封面分开。
4. AI 停用时不再显示可发送的示例引导；启用时显示原示例，点击仅填入输入框。问答正文与依据排版保持原版。本轮不必点击发送。

如果需要再次构建发布包，在项目根目录运行 `python tools/package_frontend.py`。发布包不含数据库、业务密钥、SSH 密钥、后台文件或 PDF。
