# Windows 后台一键入口

用于当前私有后台 `127.0.0.1:8090`，保留 SSH 转发和管理员登录，不需要修改服务器或公网端口。

在本机项目目录双击 `打开管理后台.lnk`，会检查是否已有可用的本机转发；有则直接打开浏览器，没有则在后台启动 SSH，等后台响应后打开 `http://127.0.0.1:18080`。随后使用原管理员账号密码登录。重复打开不会重复启动连接。

不需要保留 PowerShell 窗口。用完可双击 `关闭后台连接.lnk`，只关闭此入口自行建立且 PID、启动时间和命令匹配的 SSH 进程，不关闭手动建立的 SSH，不停止服务器服务。Windows 注销/关机也会结束本机连接。关闭浏览器本身不会关闭 SSH 转发。

可以把两个快捷方式复制到桌面；它们引用项目里的绝对脚本路径。不要移动或删除 `tools/open_admin.ps1` 和 `D:\Documents\竞赛\AI+信息素养\GPT.pem`；移动整个项目后需重新生成快捷方式或编辑其目标路径。

脚本只读取密钥路径，不复制或打印 SSH 私钥、不保存管理员密码或业务 Key。SSH 使用已有主机认证，未禁用主机校验。若是首次 SSH 连接，或私钥有口令但尚未通过 ssh-agent 解锁，先在原 SSH 命令中完成交互认证；后台无交互启动失败会显示明确提示。

连接元数据与错误日志在 `artifacts/admin-tunnel/`，由现有 Git 忽略规则排除。日志可用于诊断，但不要提供密钥文件内容。快捷方式已生成并读回检查；脚本通过 PowerShell 静态语法检查。本轮未启动实际 SSH 或浏览器，首次双击仍需用户确认。

## 2026-10-07 启动故障修复

用户反馈双击没有反应，本机 18080 端口拒绝连接。使用与快捷方式完全一致的 Windows PowerShell 5.1 `-File` 调用复现：参数默认值中 `$PSScriptRoot` 尚为空，Split-Path 在进入主流程之前报错；由于窗口隐藏，看起来无反应。

排查时可以在本机 PowerShell 使用原脚本加 `-Diagnostic`，会把错误写入终端。正常双击仍保持隐藏 SSH 窗口及自动打开浏览器的行为。

```powershell

```

关闭本入口建立的连接：

