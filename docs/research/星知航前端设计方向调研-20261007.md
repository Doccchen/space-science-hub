# 星知航前端设计方向调研

日期：2026-10-07。阶段：设计调研与方向建议，尚未选择最终方案。依据本地前端源码、最新实施记录与第一方网站资料；本轮没有修改或部署前端。没有对参考站点进行完整浏览器视觉和性能验收，官方描述与本站设计提案分别列明。

## 结论

推荐以「航天科技杂志」为主体，加入「工程蓝图」的品牌细节。新闻承担视觉吸引，AI 问答承担理解，资料页承担继续学习。三个栏目共享颜色、字体、轨道图形和导航，但使用适合各自内容的版式。

有设计感主要来自：内容主次明确、版面比例有变化、品牌图形可识别、真实素材有质量、交互反馈统一。单纯加渐变、阴影、玻璃或星空背景不足以形成完整设计。

## 现状依据

项目 README 将星知航定义为航天新闻、知识库科普问答和资料下载平台。`web/index.html` 及 `docs/acceptance/简洁前端UI实施记录-20261007.md` 表明当前设计采用浅色纯底、较小标题、细线新闻列表、统一中文字体与精简入口。

这适合高效查阅，但视觉变化集中在控件而非内容编排。以下是基于源码和记录的设计判断，不是线上截图审查结果。

## 第一方依据

1. [NASA 品牌规范](https://www.nasa.gov/nasa-brand-center/brand-guidelines/)：数字字体明确分工，Inter 用于展示和标题、Public Sans 用于正文、DM Mono 用于数字及小标签。可借鉴的是层级与用途分工，中文网站应另选适合中文的字体组合。
2. [ESA 2026 品牌更新](https://www.esa.int/About_Us/Branding_and_Partnerships/A_new_chapter_for_ESA_s_brand)：2026-06-04 官方说明新视觉体系以地轴 23.4° 倾角、更新的标识和影像组织视觉语言。可借鉴「用一个与主题有关的图形规则贯穿品牌」，本站可使用自己的轨道弧线或工程标注。
3. [NASA Eyes](https://science.nasa.gov/eyes/)：官方将其定义为利用真实 NASA 数据与影像的交互式三维可视化应用。适合启发专题探索体验；本站现有新闻/问答业务没有同样的数据和三维能力，不应以虚构仪表盘模仿。
4. [Stripe Press](https://press.stripe.com/)：官网以出版物、封面与书籍内容为中心。可作为资料库的实体书视觉和阅读内容组织参考。此处没有把它作为中文排版规范或航天行业标准。

这些案例用于寻找设计机制，不代表「2026 流行趋势排名」。

## 三个方向

| 方向 | 视觉语言 | 本站怎么用 | 代价与限制 |
|---|---|---|---|
| 航天科技杂志，推荐 | 深蓝刊头、暖白阅读区、大字标题、图片裁切、不对称网格 | 新闻形成主稿与次稿层级；AI 使用阅读式回答与依据区；资料突出真实封面 | 中等实施成本；主稿图片要匹配内容；不能暗示未实现的编辑推荐机制 |
| 轨道工程蓝图 | 墨蓝、青色和少量橙色；局部坐标网格、轨道线、等宽数字和编号 | 导航/栏目标题沿用工程标注；筛选像控制条；资料像工程档案 | 中等成本；长正文用实底；装饰性数字不冒充真实监测数据 |
| 沉浸太空展厅 | 大幅航天影像、深浅章节切换、缓慢轨道或镜头动效 | 首屏和未来专题用体验叙事；常规新闻仍保留可快速浏览的列表 | 素材和性能成本较高；需要静态降级与移动端适配；不宜全站都采用重动画 |

以上色彩、版式和动效是本站提案，并非参考网站全部采用的同款配置。

## 推荐方案如何落地

### 颜色与字体

候选色：深蓝 `#10233F`、暖白 `#F3F1EA`、橙色 `#E66A35`。深蓝用于刊头/导航/重点区域；暖白用于长文本；橙色用于少量主动作与视觉焦点。错误、服务停用、来源异常采用独立语义样式，实施时验证对比度。

标题采用具有明显字重的中文黑体；正文保持易读中文黑体；中文宋体可用于少量专题标题；等宽字体只负责日期、编号和技术标签。建议桌面栏目展示标题从 40–56px 探索，移动端从 28–36px 探索，正文 16–18px；这些是原型起点，需要用实际标题长度验证。

### 航天新闻

顶部保持三个栏目可直接切换。新闻头部可采用「主稿约三分之二宽 + 两条次稿约三分之一宽」，下方继续新闻列表与筛选。主稿最初可按当前排序确定，并明确呈现为最新条目，不能未经定义称作编辑推荐。筛选结果回到统一结果列表，避免主稿重复占用空间。

有可展示的配图时用真实图片；没有时采用认真排版的文字主稿，不随机贴星云图。本站当前排除 APOD 类条目；视觉素材选择不得改变新闻采集范围。标题、来源、日期、原文与全文入口继续承担主要信息功能。

### AI 问答

未提问时使用知识工作台布局：简短引导、主输入框、已有示例问题，搭配少量原创建筑式/工程式线稿。对话后把中心让给问题与回答；实际检索资料形成有标题的依据区域。不能为了设计擅自把模型回答改写成固定结论或伪造依据。已有服务状态、额度提示与失败处理保持清晰。

### 资料下载

采用出版物目录排版：真实封面、书名、作者与清晰下载动作。分类标题和书目编号建立秩序，借封面本身形成色彩变化。小屏使用封面加文字的列表，避免把封面压缩成难辨的装饰。沿用现有元信息，不重新加入已取消的介绍和详情弹窗。

### 动效与响应式

动效集中在按钮、导航、筛选状态和少量品牌图形；轨道线可在首屏轻微运动，阅读区保持稳定。支持减少动态偏好。手机采用单列、直接可操作的筛选和下载入口，长标题允许换行；不把桌面布局等比例缩小。

## 实施顺序

1. 先制作三个方向的同内容静态对比，使用现有新闻标题、书籍封面和真实功能入口。
2. 选定方向后统一导航、颜色、字体、间距和品牌图形；再分别实现新闻、AI、资料页面。
3. 用有图/无图、长标题、加载/失败、问答停用、资料空态检验设计，检查手机和桌面。
4. 原型确认后才进行正式前端修改与部署准备。

本轮交付为调研，最终视觉仍需通过同内容对比确认。
