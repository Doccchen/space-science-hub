# 液态玻璃网页风格调研

日期：2026-10-06。对象：现有航天新闻与资料下载页面。只调研和提出方案，没有修改前端或安装组件库，没有执行浏览器视觉验收。

## 1. 官方原则与网页实现的区别

[Apple WWDC25：Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)介绍了光学折射、动态适应和交互反馈，也明确强调控件导航层与内容层分开，避免把表格等内容全部玻璃化，以及避免玻璃叠玻璃。无障碍透明度、对比度和动态效果是材质设计的一部分。

本项目据此采用玻璃导航与操作层、稳定的新闻和书籍内容层。这是针对网页的信息结构转译，不是复制Apple品牌、原生界面或系统行为。

网页中[backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)可提供背景模糊等效果，结合透明背景、边缘高光和阴影形成轻量材质。它本身不等于真实折射，更不会自动提供Apple原生材质的自适应文字对比。

默认实现建议自行编写少量CSS，以标准属性和降级材质为主。若小型演示对比证明SVG折射能改善关键导航且手机性能可接受，再选用一个固定版本并保留许可。首版无需变更React/Vue框架或添加WebGL渲染。

## 3. 可访问性与兼容性

[W3C文字对比规范说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)要求按文字与实际背景核对对比。透明背景会变化，所以不能只测试CSS里两种色值；需要在最明亮/最复杂背景与滚动状态下检查。

[prefers-reduced-transparency](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-transparency)可作为支持浏览器中的系统偏好信号，但不能作为唯一方案。本项目应额外提供手动“减少透明效果”，同时支持prefers-reduced-motion和backdrop-filter不可用时的实色降级。

浏览器差异、手机合成层、长列表滚动、弹窗背景与原生下拉菜单都需实测。标准CSS的模糊效果和SVG背景折射不能当作所有浏览器完全一致的能力。

## 4. 当前项目观察

现有背景为#FAFBF9，文字#202B33，主色#234E67；页面使用黑体操作文字和宋体阅读标题。新闻为细分隔线行式列表，资料页为四列封面网格，24张真实JPEG加4个占位，阅读弹窗宽度约900px。

现有优点：层级简单、原文链接与阅读方式有明确边界、封面真实、功能轻量。视觉提升空间：顶部导航较平、筛选区分散、新闻条目与操作缺少材质层次、书籍卡片缺少统一容器和操作层。

当前工作区存在未提交的新闻阅读、人工审核及存储相关实现。美化阶段必须以实际最新代码建立基线，不能把本次调研时的状态写成新的服务器验收结论，也不能覆盖其他未提交功能。

## 5. 推荐结论

建议浅色冰蓝玻璃为主：限定玻璃应用范围，通过柔和环境底色、导航与筛选浮层、边缘高光、圆角和小幅反馈建立视觉特征。新闻阅读正文采用接近不透明的白色表面，资料封面保持清晰无滤镜，玻璃只组织控件和卡片外壳。

用户已确认浅色冰蓝玻璃。深色星空可作为第二阶段主题，不让双主题拖延首版，不使用动态星空视频、持续粒子和大面积逐帧折射制造额外开销。
