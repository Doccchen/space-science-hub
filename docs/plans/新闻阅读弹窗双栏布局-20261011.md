# 新闻阅读弹窗双栏布局

按用户要求，将新闻阅读弹窗改为左侧新闻正文、右侧科普解读与提问。沿用现有米白、深蓝和橙色的视觉体系，仅调整阅读弹窗的布局。

桌面宽度不低于 980px 时，弹窗最长 1380px，新闻栏与科普栏约 1.35:1，左右各自滚动；关闭按钮位于共同顶部栏。新闻标题、来源、正文、图片、原文链接与返回按钮保留在左侧。科普状态、回答记录、生成按钮及提问表单放在右侧。

不足 980px 时改为新闻在上、科普在下，并使用统一滚动，避免手机上双栏过窄。加载、读取失败、权限重新检查失败仍使用原有单栏状态提示和重试逻辑。

科普模块仍使用原有开关、会话、请求与用量逻辑。改为挂载到右侧容器后，模块销毁观察器继续监听稳定的阅读器主体，确保关闭、切换新闻或权限重新加载时清除旧轮询。

变更文件：`web/news-reader.js`、`web/news-agent.js`、`web/news-agent.css`、首页阅读器脚本版本及前端打包清单。主页面三份 CSS 入口继续保留，不重排其它页面。

验证：JavaScript 语法、设计系统检查、CSS 构建一致性检查、前端发布包生成与 diff 空白检查通过。本地固定样例预览确认左右分栏、独立滚动样式、模拟回答展示、关闭返回与重新打开后的会话恢复；未调用线上模型。截图位于 `artifacts/news-agent-preview/reader-split-preview.png`。本次未部署服务器，也未推送 GitHub。
