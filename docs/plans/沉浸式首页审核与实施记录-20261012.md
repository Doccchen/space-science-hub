# 知航沉浸式首页：审核与实施记录

2026-10-12。已完成本地实现及本地浏览器验证，未部署、未推送。原方案中的“当前任务只编写方案”为编写时的历史范围，本次执行依据是用户“先审核方案，然后按方案进行”的明确请求；文档中的示例指令没有当作额外授权。

## 审核结论与调整

方案可实施，采用原生 HTML/CSS/JavaScript、现有 `main.page` 与 hash 路由，不改后台接口。采用延续品牌的局部扩展：主角是官方照片，低信息密度、克制景深与手动转场。设计校准：构图变化 5、运动 5、信息密度 2、素材依赖 10、品牌保持 9；叙事角色为影像入口，面向手机与桌面近距离观看，整体安静，升空图承担动势。

实际审查并处理的问题：

1. `studio.js` 和 `news-reader.js` 都依赖新闻作为原入口，统一改为 gallery；`#home` 仍为 AI 问答。新闻正文 deep link 直接进入阅读弹窗，不经过欢迎。
2. 全屏裁切与保留箭体、喷焰有冲突。默认以 contain 保留完整照片，允许深蓝留边；桌面标题避开主体，手机标题置于照片下方。观看模式可隐藏标题和导航，支持 2 倍放大、拖动和键盘平移。
3. 原候选“试验箭与荒漠”实际画面为离地升起，描述改为“向上探索”，不写“静静矗立”，不凭文件名推断任务日期或型号。喷焰近景标题放在左侧，避开右侧发动机。
4. 切换使用请求序号，过期结果不更新图片与文案；新图失败保留现图。首次失败、目录失败和 8 秒超时都有重试与新闻入口；欢迎另有 2.4 秒硬期限，失败不会锁住导航。
5. 旧打包器的固定清单无法完整发布新首页。新增 `package_gallery.py`，原 `package_frontend.py` 在检测到 gallery 时委托新打包器。新脚本支持嵌套图片目录、资源先于入口安装、校验和、既有回退流程与上线前基线哈希检查。
6. 授权依据仍为空，所有图片保留 pending；包标记 `deployable:false`，安装校验在写入站点前拒绝该状态。待授权依据核对、记录后重新打包；不把下载入口当成开放许可。

## 保留的合同与工作区修改

保留新闻类别、来源筛选、分页、阅读弹窗、普通问答、历史会话和资源导航；没有更改后台开关、凭据、模型、额度或数据。资源页仅把品牌回首页链接改为 `/#gallery`。共享 logo 沿用 `web/brand.svg`，未使用蓝箭标识充当知航 Logo。

开始时 Git 工作区已有 backend/news_agent.py、新闻科普可用性、新闻阅读双栏、样式入口收拢和若干工具/文档改动。本次没有重置或提交这些修改；新发布包**包含现有新闻双栏及新闻可用性前端**，不包含后台修改。实际部署前仍须核对服务器接口与版本，不能把本地样例当作服务器验收。

## 素材与交互

`web/gallery-slides.json` 记录每图描述、alt、署名、官网入口、原图 URL、原图 SHA256、权利状态、显示尺寸和每个衍生文件的大小/哈希。5 张原图均与研究清单 SHA256 相符。

每图输出 2400/1200/320 像素宽的 WebP 和 JPEG，共 30 个文件。桌面 WebP 约 162–261KiB，移动 WebP 约 50–89KiB；保留细节，低于规划预算，无生成式补绘、增清或源文件裁切。只先准备首图，成功后预取邻图；缩略图独立加载。图片实际可见时保留整图。

欢迎使用 `zhihang.gallery.welcome.seen`，完成或跳过后记录；存储失败、减少运动时直接进入。首次欢迎约 2.1 秒，硬上限 2.4 秒。按钮、索引、方向键与触屏滑动切图，无定时轮播。精细指针轻位移仅按需创建单个 rAF；离开画廊、后台隐藏或偏好变化清理动画。观看模式保留退出、切换与来源，Escape 恢复按钮焦点；隐藏导航设为 inert。

- 首次欢迎、跳过持久记录、刷新不重播。
- 按钮、方向键、连续快速切换，图片/标题/索引对应。
- 观看模式、放大、键盘平移、Escape 及焦点恢复。
- 新闻列表、阅读双栏、关闭返回与焦点，AI 路由及独立资源页回首页。
- 新浏览器直接访问新闻、AI、新闻正文：跳过欢迎。

- 手机手势、390×844 排版，以及 320×667、768×1024、1280×720、1440×900 无横向溢出。

另通过现有 `test_news_state.cjs`、`test_news_availability.cjs`、`test_frontend_availability.cjs`、`tools/check_design_system.cjs`、样式构建一致性与修改脚本语法检查；发布包路径、大小、SHA256 和图像清单一致性校验通过。
