## 仅叠加的功能

- 首次欢迎：保留已有动画、跳过、存储异常和减少运动处理，2.4 秒硬上限；普通首页首次访问播放，新闻/AI/正文深链接直接进入。关于页提供重看入口。稳定的浏览器记录 key 不变。
- 新闻阅读：正文位于左侧，科普位于右侧；保留关闭、返回、权限变化清理与焦点恢复。小屏沿用已有双栏实现的上下排布。比较线上文件后，仅保留双栏 DOM、对应 CSS 和 Agent 脱离阅读器时的清理监听适配。
- 12 张轮播：用户确认保留线上原有 5 张历史影像，再补 7 张蓝箭影像。原 5 条数据逐字段保持，包含原署名、许可和 AI 增清说明；新增整箭与晚霞、晨昏工位、试验箭与荒漠、升空远景、点火近景、喷焰结构、试验设施。新增图片不虚构任务或日期，来源、原图哈希与 pending 权利状态保留在 history-slides.json 和 carousel-additions.json 中。继续使用线上原轮播逻辑和 8 秒调度、悬停/焦点/不可见时暂停，不使用独立画廊控制器。

新增图片日期为空时，不显示多余的分隔符；其它轮播控制代码与线上一致。
