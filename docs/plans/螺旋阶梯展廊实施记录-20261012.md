# 知航 · 3D 螺旋阶梯交互式展廊

2026-10-12。用户确认螺旋展廊方向，并要求增加图片。本轮已在本地实现，保留首页原路由、首次欢迎、来源记录、完整图观看及既有功能；不包含线上部署或 Git 推送。

## 构图与运动

沿用知航深蓝、纸白、橙色及现有品牌字体。桌面左侧叙事、右侧展位；照片作为有厚度边界的展板，台阶围绕中央轴线逐层上升。当前照片保持正面且完整，前后展位提供纵深，当前展位带橙色边框与“查看全图”入口。手机缩小展位与层间距离，标题放在展廊下方。布局不增加新的全站框架或外部字体。

渲染层为 **CSS perspective + preserve-3d**，图片是实际平面，台阶沿真实三维坐标排列。移动的是整个世界，不是用平面位移模拟照片旋转；无需新增 WebGL 依赖。每个展位转角 60 度，桌面层高 130px、半径不超过 450px，手机层高 90px、半径 250px。夹角与半径经过截图复查，避免邻图穿入当前展位。

- 邻近切换：世界旋转并上下平移，750ms，cubic-bezier(.16,1,.3,1)，停稳后阅读。没有自动巡航或定时换图。
- 拖动：按下记录，超过阈值才开始，单个按需 rAF 更新，不和 CSS transform 过渡同时运行；释放后定位展位。纵向触屏手势保留滚动。
- 大跨度索引：距离超过两层时直接定位，避免连续旋转多圈。按钮和左右/上下方向键均可导航。
- 当前展位：点击进入完整图；其它可见展位点击前往，始终保留拖动和点击提示。背向镜头或不可见的展位 hidden/inert，避免键盘落入不可见目标。
- 观看：退出、来源及切换仍可用，支持放大、拖动与键盘平移；Escape 返回展廊并恢复焦点。
- 减少运动：跳过空间变换与欢迎动画，只展示当前正面照片，按钮/索引/滑动仍可用。离页、隐藏、偏好变化清理动画与拖动状态，无永久渲染循环。

场景的只读诊断入口为 `window.galleryScene.snapshot()`，提供当前层、目标位置、rAF、半径、矩阵及可见台阶/展位数量。测试同时读取浏览器实际绘制矩阵，并用真实鼠标与触屏事件驱动，不以目标变量变化冒充动画。

## 12 张影像与来源

顺序：整箭与晚霞 → 晨昏工位 → 暮色工位 → 箭体上部 → 试验箭与荒漠 → 升空远景 → 点火升空近景 → 喷焰与箭底结构 → 总装厂房 → 工程长廊 → 发动机组件 → 试验设施。

来源仍为蓝箭航天官方影像下载。沿用本地候选 URL 清单，新下载 6 张官方原图（9、11、18、20、21、26），加入原图尺寸与 SHA256 留档；升空远景原图已在此前研究中保存。没有根据文件名推断日期、型号或任务，没有加入处理方式未确认的星空图。

`web/gallery-slides.json` 包含描述、alt、信用署名、官网/原图入口、原图 SHA256、权利状态及衍生文件清单。共 72 个展示资源：每张图的桌面、移动与缩略图分别提供 WebP/JPEG。桌面最多 2400px 宽，较小原图使用实际 1920/2000px 宽，不向上放大；srcset 使用实际输出宽度。桌面 WebP 约 71–420KiB，移动约 32–140KiB。所有来源保持公开展示授权待核（pending）。

当前高清图加载、解码后才提交图片、标题与场景状态。初始优先首图，成功后预取邻图；远处展位使用小缩略图。快速切换过期结果不提交，失败保留原展位并允许重试。
