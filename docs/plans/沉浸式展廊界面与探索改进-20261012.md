# 知航 · 全屏沉浸式展廊改进

2026-10-12。依据用户提供的设计参考，继续改进已确认的 12 图螺旋展廊。参考材料提供的是设计方向，不代表每个网站的名称、奖项、技术或图片数量均已核实，也不把每个案例当成必须逐项复制的要求。

## 核实并采用的参考

- [Christie Hemm Klok 的制作说明（DatoCMS / Luke Tongue）](https://www.datocms.com/partners/luke-tongue/showcase/christie-hemm-klok)：作者介绍图片优先的可拖动画布、接近屏幕才加载的图像，以及由缩略图展开的查看器。借鉴探索提示、按需界面和放大转场，没有复制其品牌或照片。
- [Ottografie 的设计方说明（Exo Ape）](https://www.exoape.com/work/ottografie)：设计目标是减少 UI 干扰，让摄影自然地从一个状态进入另一个状态。借鉴收起导航与说明、保持影像连续性。
- [Codrops：滚动响应的深度画廊（Houmahani Kane）](https://tympanus.net/codrops/2026/03/09/building-a-scroll-reactive-3d-gallery-with-three-js-velocity-and-mood-based-backgrounds/)：作者介绍滚动驱动、有边界的深度探索，以及从影像色彩出发的环境变化。仅借鉴滚轮输入和边界处理；当前项目仍使用 CSS 透视，没有宣称复刻特定的“16 张 Three.js 螺旋到平铺”案例。

## 最终变化

1. 展廊占满一个视口，照片移到中央，取消常驻大标题、展板边框和说明条。桌面主图约占视口宽度的 70%，保持全图比例；来自当前影像的模糊色彩延伸到整个背景。
2. 默认收起索引和操作栏。常驻入口只保留轻量品牌、菜单和“显示界面”。导航、影像说明、原始出处、索引和序章位于可唤出的菜单。关闭说明、菜单、完整图都有明确控件和键盘退出。
3. 精细指针设备显示操作栏后，空闲约 5 秒自动收起；键盘焦点仍在操作栏、菜单或说明打开时不会夺走交互。隐藏容器使用 inert，避免不可见焦点。
4. 首次操作前保留“滚动 / 拖动探索 · 点击影像看全图”提示；完成探索后减少文字干扰。鼠标滚轮按阈值推进一层，带节流和首尾边界，不拦截菜单、索引或图片放大手势。
5. 点击当前照片时，从展位的位置与尺度展开到全屏查看；返回时逆向收回。使用实际图片边界、比例与 clip-path 处理纵向展位到完整横图的过渡，不使用固定坐标冒充飞入。
6. 手机展位约为 88vw × 72svh，按主体焦点纵向取景，晚霞、晨昏、喷焰分别调校位置；点击后始终可以查看完整图。没有裁切或改写原始文件，显示取景已如实写入素材清单。
7. 手机纵向取景需要较大的源图，srcset / sizes 据此选取展示资源；背景只用小图并模糊，不加载原始大文件。减少运动时跳过旋转、欢迎与飞入，保留图片和全部入口。

欢迎的本地 key、12 图顺序和原图来源保持；新闻、AI、资源页及正文 deep link 的行为保持。用户已有新闻双栏和可用性前端修改仍包含在本地快照，未修改后台、额度或凭据。
