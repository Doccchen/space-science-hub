## 实现与部署

- 新闻客户端请求 `has_thoughts=true` 以取得检索工具观察；仅提取指定 `search_knowledgebases/api` 动作的 observation JSON.nodes 中合法 file 文档 ID/名称，不解析规划或字符串中的伪JSON。
- 文档元数据有深度、数量、长度与ID格式限制；重复来源合并。未知工具、模型正文、旧 doc_references 和 malformed observation 不能建立可信知识来源。
- `knowledge_sources` 保存这类元数据；`knowledge_evidence=tool_observation` 仅标实际检索。没有来源时继续 unverified。答案提示仍注明“检索记录不代表结论已逐条核实”。
- 阅读页以 textContent 展示“本次知识检索：《文档名称》”，不发布签名URL，不执行模型HTML。文档名称同样清理 Key、MCP Key、workspace 与上游 session。
- 探针元数据脱敏遗漏经审查发现后已修正，写文件/打印前统一递归清理已知秘密；实际采集文件仅含正常文档名称和ID，无凭据。规划和检索正文仍不进入日志。
- NASA未适配路径返回 unsupported，有回归证明没有抓取/模型调用；路径白名单保持原范围。

验证：本地31 passed、7 subtests；Linux隔离镜像63 passed、13 subtests；Python编译及diff检查通过。双轴审查阻塞项已修复并复核。发布时没有新增模型调用。可信来源适配器以本轮真实工具字段及离线拒绝/脱敏回归验证，没有为重验代码再重复收费测试；现有真实采集文件仍是适配器加入前的历史结果。
