# 前端科普入口与样式整理

本次仅实施用户选择的三项：新闻科普入口反映开关、主页面 CSS 收拢、新闻摘要排版。首屏轮播高度、普通 AI 停用页面、检索功能、资源页图片与布局均不调整。

## 新闻科普入口

新增只读 `/api/news-agent/status`，返回实际服务可用状态及公开说明，不读取新闻正文或发送模型请求。新闻列表的科普按钮先禁用等待状态，开启后显示“科普解读与提问”，关闭后显示“新闻科普暂未开放”并禁用；状态请求失败时显示“新闻科普状态暂不可用”，避免把网络错误伪装成已关闭。

列表首次加载、回到新闻页面、页面重新可见和手动刷新时读取状态；新闻页面可见时每 15 秒更新一次。并发刷新合并为同一请求。新渲染行直接使用已有状态，不为每条新闻单独查询。最终请求准入仍由后端已有开关控制，轮询间隔内不绕过服务关闭。

## CSS 入口

主页面由 10 个 CSS 链接改为 `styles/base.css`、`styles/components.css`、`styles/pages.css` 三个。`tools/build_styles.py` 按原始先后顺序生成，保留原规则及媒体查询，避免 CSS 合并意外改变其它页面。源文件的职责与维护方式见 `web/styles/README.md`。

既有独立资源页及历史脚本继续使用原 URL。前端打包脚本自动生成并包含三份样式和科普状态模块；动效脚本不再给已使用页面样式入口的首页追加旧动效 CSS。

## 摘要排版

新闻摘要使用独立 `.news-summary` 类：正文字体 `var(--sans)`、16px、1.85 倍行高、最长 68ch，并允许长词换行。现有摘要截断行数及新闻元信息字体保持原样，不修改全文阅读器或摘要内容。

## 验证与发布范围

新闻 Agent 与独立额度 52 项测试通过，包含新增全局状态接口的开关反馈和 no-store 检查。前端状态用例验证初次请求合并、开启与关闭、后续渲染行、失败与恢复、非法状态响应；设计检查、CSS 生成一致性检查及前端发布包生成通过。

2026-10-11 已按用户要求同步部署状态接口和前端资源，详见 [部署记录](../deployment/前端科普入口与样式整理部署-20261011.md)。单独发布前端到旧后端时，入口会保持不可用以避免错误放行。本次没有推送 GitHub。
