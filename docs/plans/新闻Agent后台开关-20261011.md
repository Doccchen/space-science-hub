# 新闻 Agent 后台开关

后台“新闻 Agent”页面新增“启用新闻 Agent 科普问答”复选框。修改后先保存新闻配置草稿，再应用新闻配置草稿。服务每秒同步一次，后台同时显示目标开关、实际运行状态和各历史版本的开关值。

开关和独立额度一起保存到新闻配置版本。保存草稿不会影响运行；应用后无需重启。关闭会拒绝新建会话和提交新任务，已接受的任务继续完成并正常记账。用户仍可查看任务结果和清除个人会话。普通知识库问答的开关和额度不受影响。

开启需要服务器已有 API 凭据、正文读取和连接配置。应用开关本身不发送模型请求；配置不足时显示加载失败，公开问答保持不可用。凭据继续由原有服务器配置维护。

旧额度版本没有开关字段时沿用 `NEWS_AGENT_ENABLED`。从后台保存新版本后，版本中明确保存的开关优先于环境变量，重启时读取已应用版本。原有登录、CSRF、修订冲突检查和应用审计继续适用。

本次修改涉及 `admin_web/news-limits.js`、`backend/news_limits.py`、`backend/news_agent.py` 和 `backend/app.py`。2026-10-11 已同步部署管理后台和公开站点后端，详见 [部署记录](../deployment/新闻Agent后台开关部署-20261011.md)。新闻 Agent 保持关闭，管理员可在后台应用开启配置。

验证：`python -m unittest tests.test_news_limits tests.test_news_agent`，52 项通过；`node --check admin_web/news-limits.js` 和修改文件的 `git diff --check` 通过。新增用例覆盖草稿不生效、应用后开关变化、持久化优先级、开启配置不足、旧版配置兼容、非法开关值，以及生成中关闭后原任务完成、恢复开启后新请求成功。
