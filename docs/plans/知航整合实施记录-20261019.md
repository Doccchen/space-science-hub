## 之后如何继续

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-reader.txt
.\start-integrated.ps1
```

当前机器已有独立阅读助手的 PDF 运行环境，可只读使用它，不必修改旧项目：

```powershell
.\.venv\Scripts\python.exe -m tools.run_integrated_site --reader-python ..\output\zhihang-literature-reader\.venv\Scripts\python.exe
```

启动成功后网关应显示 `INTEGRATED READY http://127.0.0.1:8878`。网址分别为主站 `/`、阅读 `/reader/`、书架 `/assets/resource-navigation.html`。本轮没有成功启动它，不能直接认为该网址现在可用。

测试命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_temporary_reader.py tests/test_site_gateway.py -q
```
