# 知航 · 全屏横向影像画廊试用

2026-10-12。按用户“先试试第一个”的选择，将首页切换为单张、横向切换的摄影画廊。

当前版本一次只展示一张照片。桌面按图片原比例铺开，保留少量米白留边；手机延续已调校的主体纵向取景，点击后查看完整图片。12 张内容、欢迎动画、共享米白/深蓝/橙色角色、菜单、来源说明和按需展开的界面均保留。

图片切换采用约 480ms 的轻微横移与交叉淡入；拖动时图片直接跟随，释放超过阈值切换一张。方向键、按钮、触屏和滚轮均可操作，无自动播放。减少运动时不位移，直接更新照片。加载或解码失败保留当前照片，快速操作仍使用原请求序号丢弃过期结果。

展开的索引增加真实缩略图，便于直接选择任意照片。查看完整图仍保留展开/收回过渡、放大、平移和明确退出。新闻、AI 问答、资源导航和正文深链接保持。

实现为 `web/gallery-horizontal.js` 和 `web/gallery-horizontal.css`，由现有 gallery.js 管理加载与查看状态。旧螺旋源码保留在项目中作为对照，但首页不加载它们；没有生成阶梯、空间轴或旋转场景，背景使用共享米白表面。

样式入口由 tools/build_styles.py 重建。沿用本地浏览器检查，并将旧空间矩阵断言改为横向拖动与切换过渡断言。桌面、手机、欢迎和全图截图更新到 artifacts/gallery-verification。素材公开展示权利仍待核，未部署或推送；本地包为 zhihang-horizontal-gallery-local-20261012.tar.gz。
