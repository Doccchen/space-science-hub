# 统一 API 管理

状态更新：已部署，详见 [部署记录](../deployment/统一API管理部署-20261020.md)。两项文献来源默认停用；按用户选择未传输本地 Key。下文记录本地实现阶段的设计与验证流程。

## 管理入口

原「AI 设置」改为「API 管理」，包含百炼知识问答、万方、ScienceDirect 三个页签。百炼沿用原有版本、额度、应用、回退及问答测试实现；文献来源采用独立配置，不修改原百炼数据库表或运行配置。

文献管理支持：

- Key 加密保存，不回显，不放入浏览器存储；ScienceDirect 可选 Insttoken 单独加密保存。
- 草稿、显式应用、上一应用版本回退；修订号冲突时拒绝覆盖。
- 保留或清除密钥、来源启停、单次超时、每日实际调用上限。
- 固定查询的显式连接测试，需要勾选确认；不自动重试、不自动应用测试版本。
- 北京时间每日计数，缓存命中不计调用；失败和测试均计入。测试另限制每小时 3 次、24 小时 10 次，不因切换配置或重启进程重置。
- 配置历史、近期测试、用量、检索进程心跳和加载版本；「已生效」只表示加载完成，不代表远端 Key 已验证。

## 运行与权限

新增 `/api/literature-config` 路由仅挂载私有管理进程，复用管理员登录、Origin 和 CSRF 校验。公开主站和论文检索服务不提供管理接口或密钥读取接口。

首次点击「初始化文献 API 管理」后，万方与 ScienceDirect 默认停用，后台数据库成为这两项来源的权威配置；环境变量不会自动导入或在停用时重新启用。初始化不会触发外部请求。

密钥使用现有独立主密钥 `AI_MASTER_KEY_FILE` 通过 Fernet 加密，版本与调用日志位于现有 `MANAGEMENT_DB_PATH`。加载失败时停止附加来源并保留基础四源，后台显示失败，不降级回旧环境凭据。

论文检索进程每两秒检查应用版本，新请求采用新配置，清除旧来源缓存；已经发送的请求不因配置修改而重发。实际请求前再次核验应用版本与限额，防止旧服务快照绕过停用。ScienceDirect 不在服务缓存或浏览器研究历史中保存检索结果，刷新后提示重新检索；原始记录保留来源和回链。

万方按 AI HUB 官方文档接入 `https://api.wfdata.com/openwanfang/getQuery`；ScienceDirect 使用官方 Search V2 PUT 接口 `https://api.elsevier.com/content/search/sciencedirect`。两者均固定官方 HTTPS 地址、不跟随重定向，不下载全文。API Key 不代表供应商已授予本站对访客展示数据的权利，启用前须由运营者核对已有授权。

参考：[万方文档](https://github.com/wanfangdata/wfdata-open-skills)、[ScienceDirect Search V2](https://dev.elsevier.com/documentation/SCIDIRSearchAPI.wadl)、[Elsevier 联合检索说明](https://dev.elsevier.com/federated_search.html)。

## 正式部署要求

本版已由专用 `deploy_api_management.py` 发布。不能用仅更新静态文件的上一版研究助手部署脚本发布本版：后台与检索 Python 进程需要更新并重新加载。

- 更新私有管理进程、论文检索进程所需的 `backend/literature_*.py` 与 `reader/` 模块、后台资源及研究助手资源。
- 私有管理与论文检索进程必须挂载同一持久管理数据库和同一独立主密钥；检索进程需要读写数据卷以更新心跳与调用记账，主密钥只读挂载。
- `compose.api-management.yaml` 为本仓库 `compose.reader.yaml` 中 reader 服务的附加挂载配置；若服务器独立 Compose 中服务名不同，先按实际服务名调整，不直接新建第二套检索容器。
- 在保留生产数据库及独立主密钥的前提下备份、更新镜像并重启相应进程；保持后台仅监听本机及现有 SSH 转发入口。
- 运行后登录私有后台，初始化文献管理，输入真实 Key，保存草稿，主动测试，再应用并检查加载版本与心跳。没有 Key 时无需启用，基础四源继续运行。

## 验证

40 项后端测试通过（统一管理、万方、论文检索、原百炼管理），另有脚本语法检查。覆盖登录/CSRF、私有路由、不回显 Key、密钥加密与清除、并发修订冲突、应用与恢复、热加载与主密钥错误、按日记账和缓存、测试确认及共享限额、ScienceDirect 请求头与字段映射。

隔离浏览器验证初始化、密钥保存后清空输入框、应用版本、模拟连接测试、三个页签切换及表单状态。桌面、平板与手机布局检查；这不等于真实供应商接口认证通过。

| Before | After | Why |
| --- | --- | --- |
| 百炼独立设置，文献来源依赖配置文件 | 三个服务的统一管理入口 | 在后台维护服务连接与启停 |
