# 新闻与资料页面液态玻璃美化方案

日期：2026-10-06。阶段：调研后的设计提案。规划方交付方案，实施Codex负责原型、代码、验证与部署；本轮不修改功能代码，不自动提交或推送。

用户已确认主视觉：浅色冰蓝玻璃。下述方案以该方向为准，深色主题不属于首版范围。

布局优先级更新（2026-10-06）：本轮重点调整新闻分类/筛选和新闻分页的位置、分组与视觉层次。顶部“航天新闻/科普Agent/资料下载”栏目导航的位置、形态和交互后置，不列为本轮改造项；仅允许为统一配色作必要样式协调。本方案所述玻璃操作层以新闻筛选与分页为主要落点。

## 1. 设计方向与范围

推荐视觉方向：浅色冰蓝液态玻璃。采用Apple公开材质原则的网页转译，使用现有网站身份、真实新闻和电子书封面。不是Apple品牌仿制，也不承诺Web版与原生Liquid Glass完全一致。

改造模式：视觉与局部布局重设计，保留产品结构与行为。重点新闻分类筛选区、分页区、新闻列表/阅读弹窗和资料下载页；顶部栏目导航布局后置，AI演示页与管理员界面不扩大重设计范围，共享基础样式只做必要兼容。

布局变化5/10：保留熟悉的列表与书架，导航/筛选重新组织；动效3/10：仅交互反馈；新闻密度6/10、资料密度6/10：首屏看到内容，不做全屏宣传；素材依赖3/10：用真实封面与受允许新闻图片，默认不依赖新壁纸；品牌保持7/10：保留网站名称、蓝色识别和栏目。

用户未提供新的品牌参考图。以[调研记录](../research/液态玻璃风格调研-20261006.md)和当前代码为依据，采用自定义冰蓝材质系统，不照搬Apple硬件宣传页布局。

## 2. 设计系统建议

| 项目 | 初始设定 |
|---|---|
| 页面底色 | #F2F6FC，辅以非常浅的冰蓝/银白环境色，无动态背景 |
| 主要文字 | #172B45 |
| 次文字 | #52627B，按实际背景验证对比 |
| 主操作 | #275ED7，少量用于当前选中与主要按钮 |
| 内容表面 | #FFFFFF或接近不透明白色，正文不被背景穿透 |
| 玻璃表面 | 半透明白色，初始不透明度0.72—0.88，结合背景按测试调整 |
| 模糊 | 导航/筛选先试12—16px；小屏6—10px或实色降级，数值为设计起点不是性能保证 |
| 边缘 | 一圈细白高光与轻微冷色描边，避免厚霓虹轮廓 |
| 阴影 | 浮层一层柔和阴影；内容卡片轻微分离，不反复叠多重阴影 |
| 圆角 | 导航/浮层20—24px；卡片16—20px；输入12—14px；主要按钮胶囊形 |
| 间距 | 4/8/12/16/24/32/48/64px，统一内容节奏 |
| 字体 | 保留现有可用中文字体与系统回退；界面黑体、新闻长文保持适读排版，不为仿Apple额外下载受限字体 |
| 字号 | 页面标题36—44px，小屏28—32px；新闻标题20—24px；正文16—18px；元数据12—13px |
| 动效 | 控件状态150—220ms，弹窗180—240ms；不持续抖动、视差或波浪变形 |

视觉重点是清晰材质与层次，不将所有区域涂色。实际透明度、文字、边缘和阴影要一起验证，不能以透明度越低代表设计越好。

## 3. 顶部栏目导航：后置优化

本轮保留现有文字标识、栏目位置、切换方式和主导航事件，不迁移为居中浮动胶囊，不新增sticky布局。允许协调字体颜色、焦点与背景色，保证新闻/资料页新主题下可读。

居中玻璃条、sticky导航和手机栏目切换形态留作后续独立设计，不因为本轮液态玻璃风格默认执行。基本触控可达性、清楚选中状态及现有焦点行为保持。

后续导航优化同样避免玻璃叠玻璃；当前模糊预算主要用于筛选操作面板，选中胶囊不再单独启用backdrop-filter。

## 4. 新闻页

### 顶部与筛选

保留简短标题和一句说明，压缩当前较大开场留白。首屏应包含标题、筛选及至少一条真实新闻，不增加伪统计、热度排行榜或装饰性数字。

筛选区放在页面标题下、新闻列表上，组织成一个轻量玻璃面板，桌面两行：

第一行是新闻类别分段控件：全部 / 国内机构 / 商业航天 / 国际机构。选中项使用着色胶囊与文字状态，整组属于一个面板，不把四项做成互不关联的浮动按钮。

第二行左侧为来源与商业地区，右侧为刷新；更新时间放在该行下方或右侧小字区域，不夹在类别按钮之间。商业地区只在商业航天分类显示，来源选项由API按当前条件生成。原生select优先，若改自定义下拉必须补足键盘与触控行为。

当前代码会依次插入类别、地区、来源、提示和两套分页，实施时可用明确容器重新分组这些节点，但需复用当前筛选事件与状态，不能仅用CSS绝对定位强行拼接。

工具条在手机分行显示，查询含义、选择状态和更新时间清楚，不把所有来源展开成大量玻璃按钮。

手机类别尽量保持一组可见的四项分段控件；确实放不下时采用受控换行，不缩小文字或触控高度。来源与商业地区在下一行按空间并排或上下堆放，刷新和更新时间另行排列，禁止页面整体横向溢出。

### 分页区：顶部简化，底部为主

当前web/news-ui.js通过makePager生成顶部、底部两套完整分页，二者都包含每页条数、总量、上一页、页码、下一页与跳转。本轮主要解决重复控件造成的拥挤，保留现有page/page_size/snapshot及请求状态。

新闻列表顶部只保留简短结果栏：左侧“共N条 / 当前第X页”，右侧“每页10/20/50条”，默认20条。顶部不再完整重复数字页码和页码跳转。

新闻列表底部居中放主分页玻璃胶囊：上一页 → 首页/当前页附近数字/省略号/末页 → 下一页。数字集合沿用现有当前页前后约两页规则，页数来自API，不硬编码当前页数。当前页用明显选中态，省略号不做可点击页码。

桌面跳转输入置于主胶囊下方的次级行，可与“第X/总页数”排列。每页条数主要在顶部控制，底部不重复一套相同选择器。

手机主分页简化为“上一页 · 第X/总页数 · 下一页”，保持44px触控；数字页码不占满屏幕。页码跳转可收纳到“跳转到指定页”展开项，仍可访问。全部页面只有一套可见的主翻页操作，不采用遮挡内容的悬浮底部栏。

0条结果时显示明确空状态，禁用翻页/跳转，不呈现“第1/0页”；只有一页时显示简短总量、无需展开数字页码。加载时防止连续翻页重复请求，失败不把未成功目标页显示为当前页。

换类别、地区、来源或每页条数时重置第一页；普通翻页保留现有snapshot，刷新列表按既有规则更新快照。翻页成功后把视点移到新闻结果栏而不是整个网站顶部，并给出可见页码及适当焦点提示；尊重减少动态偏好。

布局示意：

```text
页面标题与说明
┌ 新闻筛选玻璃面板 ────────────────────┐
│ 全部   国内机构   商业航天   国际机构  │
│ 来源选择   [商业地区]           刷新  │
│ 最近更新时间 / 必要来源状态           │
└─────────────────────────────────────┘
共 N 条 · 第 X 页              每页 20 条
新闻列表
          上一页  1 … 4 [5] 6 … 末页  下一页
                     跳到第 [ ] 页
```

方括号表示条件控件或输入示意，不代表固定数据；具体状态与文字按真实API生成。

### 新闻列表

保留单列阅读结构，条目采用白色或高不透明度轻表面、16—20px圆角、合理行距和低强度边缘。列表主内容不叠加逐条实时背景模糊。

每条突出标题，其次是发布来源、时间、性质和实际阅读方式。政府文章按实际允许范围显示摘要/本站阅读；其他机构与公司按当前政策只标题、元信息和原文链接，不能为了填满新卡片增加旧摘要或新配图。

悬停可轻微改变边缘或提升1—2px，不放大文字。主要动作保持“本站阅读”或“原文↗”的真实语义。分页沿用现有实现，不在本次改为无限滚动或擅自新增推荐算法。

### 阅读弹窗

保留现有dialog与hash阅读路径，不改为独立新闻页面。弹窗外层与关闭/工具区可有轻玻璃特征，正文区采用不透明白色，最大有效行宽约720px，不能让背后新闻文字透进正文。

标题、来源、时间、阅读范围和段落层级清楚。当前正文/素材许可检查、刷新、撤回及版本检测逻辑保持，图片只按原有审核与存储状态展示。

弹窗打开背景滚动锁定、Esc关闭、焦点约束和关闭后原列表位置都保持。关闭按钮对亮背景/暗遮罩均可辨。正文滚动不通过不断改变blur值来驱动动画。

## 5. 资料下载页

### 书架

保留28份资料、24张已核对封面和4个中性占位。资料页最大宽度沿用约1180px，桌面四列、平板两至三列、手机两列或窄屏一列，按书名和按钮可读性调整。

卡片外壳采用细高光、轻描边与柔和阴影，封面本身保持真实颜色与清晰度。卡片不逐个启用动态折射；不得把封面做模糊、镜面遮罩或换成AI图。

封面维持2:3框、contain显示，长书名可以两至三行，不裁断关键版本。作者/版次、分类、格式和大小保持真实元数据。

### 操作与筛选

搜索与分类采用同一玻璃工具条体系。下载按钮使用清晰的着色主操作或高对比边框，胶囊形态，不用难辨的白字透明按钮。

本阶段为无介绍版，不新增内容介绍、PDF预览、下载完成提示、收藏、推荐或虚构下载次数。PDF继续302到OSS，视觉变化不能把下载改成服务器转发。

分页、查询防抖、取消过期请求、缺封面回退与错误重试保持。卡片图像lazy loading及固定尺寸保留。

## 6. CSS实现与性能策略

默认使用CSS变量、背景颜色、backdrop-filter blur/saturate、细边缘和轻阴影。首轮不为美化重构框架，不加入持续渲染的WebGL/Canvas背景。

增强玻璃集中于筛选面板、底部主分页和有限浮层；顶部导航布局后置。大面积列表与整页正文采用实色/接近实色；一屏最多约2—3块有明显模糊的主要区域作为起始预算，最终按实测调整，不按卡片数量无限增加合成层。

不动画blur、不常驻mousemove改滤镜、不给所有元素加will-change。小屏和减少透明模式减少滤镜范围，功能保持一致。失败/不支持浏览器通过@supports切实色、描边和阴影。

CSS色彩与玻璃只是视觉近似。SVG折射可用开源项目做单独小实验，但不默认装进生产；必须证明跨浏览器、可读性和滚动性能后，才用于极少量导航控件。代码许可与壁纸素材许可分别核对。

主要新增成本在客户端绘制与合成，不要求升级服务器、增加模型调用或变更数据库。静态文件压缩缓存与图片尺寸仍须合理，不能以服务器压力小推断所有手机都流畅。

## 7. 无障碍与降级

普通正文按至少4.5:1、符合条件的大字号至少3:1的目标核对真实背景，所有关键操作都有可见焦点和文字/语义状态。滚动时背景变动也要保持文字可读。

支持prefers-reduced-motion。在支持的浏览器读取prefers-reduced-transparency，同时提供手动“减少透明效果”选项并本机保存；此选项只改变显示，不改服务器或数据。

减少透明模式使用稳定的实色/高不透明度，关闭强折射与位移反馈。系统偏好或滤镜不支持时不出现空白、难以辨认的按钮或依赖悬停的动作。

## 8. 必须保留的合同

- 新闻类别、地区、来源、页码/游标行为和真实接口参数。
- 政府正文/其他来源仅链接的显示规则，许可与版本检查，不新增未审核正文或图片。
- 阅读弹窗hash、刷新、前进后退、Esc、焦点与滚动恢复。
- 资料搜索、分类、页码、稳定ID、28份公开范围、24封面/4占位和OSS下载地址。
- 现有页面DOM ID及pagechange/readingchange等事件，除非功能基线明确允许迁移。
- 管理端认证、新闻采集、数据库、OSS权限与AI能力状态。

只能在确认的范围内增减样式类或包装元素，不能为了视觉换掉事件绑定节点导致筛选或下载失效。

## 9. 实施与验收流程

1. 主视觉已确认浅色冰蓝；实施前记录当前变更与可运行基线，不覆盖已存在的未提交新闻实现。
2. 输出两个页面的轻量v0：真实或明确标注的数据，标准玻璃/低透明降级两种状态。新闻页必须展示类别面板、条件筛选、顶部简短结果栏及底部主分页，资料页展示书架。先评估材质、层次和手机结构，顶部导航保持原布局。
3. 方向确认后统一新闻/资料工具条及卡片体系，完成新闻分页布局、列表/弹窗和书架/下载操作。建议新增独立theme CSS，基础回退可切换，避免不可回退的全局选择器污染。
4. 用同一数据集对比美化前后：移动端滚动、筛选/分页、打开关闭弹窗、书籍搜索、占位封面与下载；检查控制台和网络请求，无额外循环取数或PDF预加载。
5. Chromium系桌面（含实际Edge/Chrome）、Firefox及可获取的Safari/WebKit验证；无法测试的环境明确记录。宽度至少390、768、1440px，键盘、触控、减少动态/透明、滤镜不支持均有检查。
6. 测试环境部署，用户在可访问网络做真实浏览器验收。功能完成并验收后统一提交与git push，方案讨论和中间改稿不单独推送。

记录首屏布局、真实文字对比、图片清晰度、滚动长任务/卡顿、布局偏移和新增静态资源大小，并与现有页面对比；不以截图好看或桌面流畅代表手机通过。

新风格不得降低真实新闻来源和时间标记的可辨性、让图片或正文可用范围误导、导致下载按钮不能点击。降级后核心操作完整可用。

新闻布局专项验收：四分类选中与API一致；商业地区仅条件显示；来源与地区联动正确；更换筛选后第一页；10/20/50每页条数切换；首/末页与省略号；页码跳转、移动端展开跳转；0条/单页/多页/加载/失败状态；快照保持；翻页成功视点和阅读弹窗关闭后列表状态恢复。顶部主导航未被意外移动或改造。

建议1天内形成v0，确认后约1—2天完成样式和交互回归；SVG真实折射、深色主题等增强单独排期，不作为基本美化验收前置。

## 10. 当前交付与待定

本轮交付为调研及设计方案，不包含网页预览或新增样式。用户已选择浅色冰蓝，下一步可交实施Codex先制作新闻与资料两页v0，供评估材质与布局，再完善实现。深色切换、SVG折射等另行讨论，不执行自动部署/推送。

本轮优先新闻分类筛选与分页，其次资料页材质与书架；顶部栏目导航布局后置。方案更新不单独提供Git推送命令，功能完成并验收后由用户提交。
