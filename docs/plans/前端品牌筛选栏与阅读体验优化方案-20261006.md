# 前端品牌、筛选栏与阅读体验优化方案

日期：2026-10-06。范围：名称与图标、去掉减少透明效果开关、新闻左侧筛选栏、阅读后新闻消失故障、阅读弹窗关闭与字体。仅提出方案，不修改功能代码、不提交或推送。

## 设计方向

保留浅色冰蓝视觉、三个主栏目与已有功能，采用局部改版。新闻页定位为信息检索页面，阅读弹窗定位为安静的长文阅读区域。电脑以左筛选右结果为主，手机使用可展开的筛选面板。

沿用深色文字 #172b45、次要文字 #52627b、蓝色强调 #275ed7、浅冰蓝背景和白色内容区域；不新增字体下载、前端框架或第三方模糊效果库。字体采用系统中文无衬线，8px 间距基准，面板圆角 16—20px，控件圆角 8—12px，玻璃效果集中在导航与筛选操作区。交互动效约 150—200ms，遵循减少动态效果偏好。

## 1. 名称与图标

建议暂定“星知航天”，说明文字“航天新闻 · 知识科普 · 资料”；备选“知航”“航天知窗”。这是产品命名建议，未做商标或同名排查，最终名称由用户选定。

图标采用一个有辨识度的轨道弧线与星点组合，少量笔画，避免细密插画；以蓝色为主，保证 16/32px 小尺寸仍可辨认。先提供 2—3 个简洁矢量草案选型，再落地 SVG 与浏览器 favicon。自行设计本站图形，不使用航天机构标识。

统一页头名称、浏览器标题、favicon、关于本站及页脚；移除标题中的“新闻测试版”。名称链接仍返回新闻入口，仓库名、服务地址与既有 hash 路由不因品牌修改而改动。

## 2. 去掉显示开关

将“减少透明效果可以不需要”理解为去掉各页面的可见开关，保留已确定的玻璃风格。清理旧开关事件与持久偏好读取，避免旧 localStorage 选择让新版效果异常；不清理其他站点设置或聊天状态。

无控件地自动遵循系统减少透明偏好，并保留浏览器不支持 blur 时的实色回退。正文仍用白底，信息可读性不依赖透明效果。

## 3. 新闻左侧筛选栏

桌面约 1024px 及以上采用两栏：左侧宽 220—240px，间隔 24—32px，右侧为结果列表；根据实际内容宽度调整断点。侧栏随页面滚动可 sticky，顶部避开主导航；内容过长时保留可达的内部滚动。

左栏依次为：

1. “筛选新闻”标题与重置入口。
2. 新闻类别：全部、国内机构、商业航天、国际机构，纵向单选，选中项有清楚的文字与底色标识。
3. 商业地区：仅商业航天类别显示，沿用现有地区定义。
4. 来源：受类别和地区约束，纵向单选列表；来源多时可折叠或滚动。保持单来源筛选语义，不擅自改为多选。

右栏顶部显示结果总数、当前筛选摘要、每页条数与刷新按钮；下方新闻列表和底部分页。抓取状态作为次要信息，不挤占筛选选项。无需新增后端搜索接口或来源数量聚合。

切换类别后清除不兼容的来源及地区，回第一页；切换来源后回第一页。阅读不改变筛选、页码、每页数量或分页快照。零结果、加载失败与上一筛选结果的过渡状态要明确，不将空白误作成功。

小屏改为列表上方“筛选”按钮，展开同一套控件并显示已选摘要；不保留挤窄正文的固定侧栏，不依赖横向滚动操作。采用单套控件响应式布局，避免桌面与手机的重复控件状态不同步。

## 4. 阅读后新闻消失

暂按“阅读中文后”指“阅读正文后”处理，若仅中文稿件发生也要分别记录。现阶段为用户报告问题，未浏览器复现，不能断言是数据库删除或已定位某一行错误。

先记录新闻 ID、类别、来源、页码与阅读前后列表；覆盖中文全文、英文全文、原文链接稿及加载失败。检查 readingchange 行替换、正文详情与列表字段差异、hash/popstate 导航、滚动恢复、焦点以及页面显示状态，关注请求晚返回和快速开关。

修复目标：阅读只更新必要的展示状态，不删除结果、不重置列表；关闭后回到原筛选与原位置。按 ID 合并行数据，避免不完整详情覆盖列表元数据；仅在复现确认需要时调整相应代码。权限撤回或新闻确实不可用时给出说明，与普通阅读区分。

## 5. 阅读弹窗

桌面居中，弹窗宽约 880—960px、最高约 90dvh；标题与正文阅读列宽约 680—720px。顶部工具条独立且持续可见，左侧“新闻阅读”，右上角简洁 × 按钮，点击区域至少 44×44px，提供“关闭阅读”可访问名称。正文单独滚动，不让关闭按钮随长文消失；底部增加“返回新闻列表”辅助入口。

长文打开时焦点置于标题，Tab 焦点留在弹窗内；Esc、关闭按钮、浏览器后退均正常退出并恢复原列表焦点与滚动位置。不自动点击遮罩关闭，减少误操作。遵循 W3C 模态弹窗焦点与键盘规范。

统一中文系统字体：标题桌面 28—30px、手机 22—24px，字重 600、行高约 1.4；正文桌面 18px、手机 16—17px、行高约 1.8；来源/日期 13—14px。段间距 16—20px，左对齐，无整段居中或额外大字距。原文署名、来源、日期与图片说明保留。

清理通用 dialog p 与阅读区专属样式的层叠冲突，明确标题、正文、元数据和注释四个层级。手机接近全屏，适应安全区，工具条保持可见，图片不超宽、表格局部横向滚动。

## 实施顺序与验收

先复现并修复阅读消失问题，再落地筛选栏与弹窗，最后统一名称图标和删除可见透明开关。预计 1—2 个工作日，取决于故障复现与品牌选择。

完成后验证：第 2 页及不同来源打开、关闭、Esc、后退均保留列表/筛选/位置；快速开关和失败重试不造成空白；桌面、平板、手机筛选与长文阅读正常；旧透明偏好不再覆盖新版；favicon 小尺寸清楚。回归 AI 问答和 OSS 下载。此轮不更改新闻采集、发布策略、知识库、下载目录或付费调用逻辑。

交付修改记录、故障原因与验证结果。功能完成且验收后，再由用户提交并执行 git push。

依据：[W3C 模态弹窗模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。左栏尺寸及排版数值为本站设计建议，不宣称源自某一论文网站的固定规格。
