# 信息核对助手 · 前端 v0

2026-10-05，使用 web-design-engineer 技能，按已确认的浅色资料工作台设计。

入口：index.html。使用 HTML、CSS、原生 JavaScript，无外部运行依赖；可直接打开，也可以运行 `node preview-server.cjs` 后访问 http://127.0.0.1:4173 。预览服务只监听本机。

已实现：首页、三组固定演示案例、差异项目选择、原文依据、完整演示原文弹窗、时间脉络、粘贴资料交互、关于页面和三种版式探索。

所有案例与来源均为虚构并明确标注。没有调用模型、联网获取来源或执行真实核对。用户粘贴资料只保存在当前页面内存，刷新即清除；点击体验按钮仍打开固定案例，不针对粘贴内容生成判断。

右下角“设计选项”提供标准工作台、阅读优先、紧凑对照三种布局。移动端改为单栏阅读，依据位于结果之后。

验证：JavaScript 与预览服务脚本语法检查通过，HTML/CSS/JS 的本地 HTTP 请求均成功。尚未执行浏览器交互验收与跨设备实测。

本原型用于确定视觉与页面结构。后续是否迁移至 React/Vite、如何接入 FastAPI 与真实智能体，待功能范围确定后执行。
