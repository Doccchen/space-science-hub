# 航天科普适配 Agent · 前端 v0

日期：2026-10-05。新入口为 aerospace.html，旧信息核对原型保持原样。

## 设计与实现

使用 web-design-engineer 技能，按原有暖白 #F7F8F5、石墨 #202B33、深蓝 #234E67 的视觉系统扩展。采用资料栏、双版本阅读、事实依据栏，宋体标题与阅读正文、黑体操作信息、细边线、小圆角、低动效。保留来源、依据、受众与能力边界，改善航天主题的信息层次。

本版本为纯前端 HTML/CSS/JavaScript，无外部运行依赖。后续可迁移到 React/Vite，不要求现在部署大型 Agent 平台。

已实现：专业摘要与高中生科普版切换、引用编号与依据联动、资料段落强调、术语词典、资料粘贴与空输入提示、演示文本导出、三种布局与字号选择、方法说明和设计参考。

## 内容边界

示例依据是 [NASA Moon Facts](https://science.nasa.gov/moon/facts/) 的 Orbit and Rotation 小节。页面输入是预先整理的中文节选，非官方中文原文。专业摘要、科普文、事实标签及材料不足说明均为预先编写，未运行模型或自动核验。

椅子类比属于预先编写的教学表达，只说明方向变化，不模拟受力与运动速度。材料不足仅表示所提供节选未给出，不代表全网公开资料都不存在。

粘贴文本仅保留在当前页面内存；刷新后清除。查看示例不会针对用户文本生成结果。导出文件明确带演示说明与来源链接。
