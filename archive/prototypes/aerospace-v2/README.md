# 航天科普网站 v2：简洁三栏目

日期：2026-10-05。按用户最新要求：取消高中生限制，面向所有感兴趣的读者。网站分为航天新闻、科普 Agent、资料下载。旧 v1 保留用于对比，当前原型入口 aerospace-v2.html。

## 页面与视觉

沿用暖白、石墨与深蓝，降低信息密度，主内容最大宽度 820px，正文采用单栏阅读。取消常驻三栏、受众选择、浮动设计面板与密集状态标签。专业摘要使用标签页；资料原文在弹窗查看，事实依据在正文下方展开。

首页为航天新闻，现仅提供已核对的官方来源入口：国家航天局、NASA News、ESA Newsroom。未接入新闻列表，不虚构新闻标题、图片与发布日期。科普 Agent 页面提供材料输入和固定示例。资料下载页面未接入文件，使用空状态。

简洁风格参考：[Starlight](https://starlight.astro.build/) 的文档阅读、[Radix Themes](https://www.radix-ui.com/themes/docs/overview/getting-started) 的控件与排版、[shadcn/ui](https://ui.shadcn.com/docs) 的可定制工具界面。三个项目核心代码均有 MIT 许可；原型自行编写，不复制项目代码与品牌素材。

## 后续功能建议，尚未实现

- 航天新闻：标题、发布日期、来源、简短导读和原文链接；先人工精选，再考虑自动更新。新闻中的“用 Agent 解读”应在真实材料传递实现后加入，不能以预写示例替代实际解读。
- 科普 Agent：公开材料输入、专业摘要与科普版本、事实依据、资料不足说明。PDF解析与真实生成仍待实现。
- 资料下载：管理员上传与编辑资料，访客浏览、预览及下载。每份资料显示标题、作者或发布单位、主题、简介、来源、格式、文件大小和公开分发条件。文件未整理，不生成虚构书目。

资料库第一版优先 PDF，可下载的其他格式按真实文件确定。PDF 可独立预览；EPUB 在线阅读需要专门阅读组件，不假定浏览器可直接阅读。后台上传应与访客导航分开，不能让所有访客默认获得公开发布权限。

已确定的阿里云 2核2G 服务器仍适合轻量前端与 API。文件量小时可使用持久目录由 Nginx 提供；大文件或下载流量增加后可考虑 OSS，避免把下载流量经由模型调用服务转发。上线前核对磁盘与带宽、配置文件大小上限，管理员上传后再发布有权公开分发的材料。当前不连接服务器、不创建云资源。

## 验证与预览

运行 node aerospace-v2-preview.cjs，访问 http://127.0.0.1:4175 ，也可直接打开 aerospace-v2.html。脚本语法与本地 HTML/CSS/JS 加载检查通过。未执行浏览器交互验收与移动设备实测。

预写科普示例沿用 NASA Moon Facts 的中文整理节选，不是官方中文原文；示例没有实时模型生成或自动事实核验。输入仅在当前页面，不上传。导出的示例文本带来源与演示说明。
