# 星知航视觉效果稿

2026-10-07。独立可离线打开的三方向视觉原型，不接入生产 API。

用户已确认先做三版同内容效果稿，沿用上一轮提案直接制作 v0。

## Design Read
- 用途：航天爱好者和工程学习者的网站效果对比。
- 模式：独立 Redesign · Overhaul 原型，正式前端不变。
- 杂志：视觉变化 7 / 动效 2 / 密度 6 / 素材依赖 8 / 品牌保真 7。
- 蓝图：视觉变化 8 / 动效 2 / 密度 7 / 素材依赖 5 / 品牌保真 7。
- 展厅：视觉变化 9 / 动效 3 / 密度 4 / 素材依赖 9 / 品牌保真 7。
- 叙事：新闻为入口；AI 提问与资料下载为继续理解的动作。桌面约一米、手机近距离阅读。温度分别为编辑感、工程感、探索感。
- 容量：首屏一篇视觉专题与两条次稿；下方三模块，移动端单列；题材在三版保持一致。

## Design Decisions
- 杂志：暖白 #F3F1EA / 墨蓝 #10233F / 橙色 #E66A35，明暗主次、2:1 编辑网格。
- 蓝图：深蓝 #10233F / 冰白 #EDF6F4 / 青绿 #8DE5D0 / 橙色 #E66A35，局部网格、工程标注和硬边。
- 展厅：近黑 #070E18 / 冰白 #EDF6F4 / 橙色 #E66A35，大画幅、底部标题、宽屏影像叙事。
- 字体：本地 Microsoft YaHei / PingFang SC 中文；Georgia 用于杂志短英文；Consolas 用于编号。无外部字体依赖。
- 间距：8px 基准；16/24/32/48/64。
- 圆角：主结构 0；控件 4–8px；无玻璃和多重阴影，封面仅投影。
- 动效：180–240ms 控件过渡；可关闭的缓慢轨道旋转，减少动态偏好自动停用。
- 来源：web/brand.svg 原有标志；web/resource-covers/ 真实封面；content/resources.json 原目录元信息。
- 主影像：earthrise.jpg；NASA 官方 https://www.nasa.gov/image-article/apollo-8-astronaut-bill-anders-captures-earthrise/ ，图片 https://www.nasa.gov/wp-content/uploads/2023/03/apollo_8_earthrise_1968_as08-14-2383.jpg 。标注 NASA，保留历史拍摄时间；只作视觉专题，不计入新闻库或改动 APOD 排除策略。
- 内容：ESA 2026 品牌更新、NASA Eyes 官方网页作为来源样例，不声称是本站实时新闻流。
- AI：展示提问前布局与原有两个示例，不发送问题，不伪造回答、额度或服务在线状态。
- 资料：展示真实目录书籍；下载动作仅提示效果稿边界。

## 交互
三个主题可切换，三个栏目可切换；新闻过滤、书名搜索、AI 输入示例、原文访问、字体密度与动效开关可操作。控制面板与原型说明置于预览工具栏，产品页面保持正常语气。

## 用户确认的融合调整

2026-10-07：用户喜欢沉浸式太空展厅新闻页，并要求用于航天科技杂志。A 版新闻首屏改用 C 版的大幅影像、左下叠加标题、暗色遮罩与原文入口；首屏下方仍为暖白杂志筛选与文章分栏。AI 和资料沿用 A 版，B/C 对照保持。默认打开 A 融合版，链接可用 `?theme=cinema` 或 `?theme=blueprint` 指定其他方向。仅调整原型。
