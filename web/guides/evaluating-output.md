## 简要原则

语言流畅、格式完整、带有引用，都不能单独证明回答正确。先拆分回答中的主张，再检查每条主张的证据。

## 操作步骤

1. 圈出可核查的主张：人名、机构、时间、数字、单位、技术条件和因果关系。
2. 将回答分为事实陈述、推测和建议。注意“可能”“预计”“已完成”等词语代表不同的确定程度。
3. 查看依据是否存在：链接能否打开？文献标题、作者和 DOI 是否对应？原文是否真的支持这句话？
4. 核对时间与适用范围：历史结果是否被写成当前状态？单次试验是否被写成通用结论？
5. 无法核查时保留不确定性，删除或标记该主张，不通过换一种问法来替代证据。

## 航天新闻示例

以下为辨别方法示例，并非真实新闻报道：

> 材料写“计划开展回收试验”，回答却写成“已实现稳定回收”。

这改变了事件状态。应回到新闻正文与发布方后续公告核对，不能用计划证明结果。

| 需要留意的表述 | 应进一步检查什么 |
| --- | --- |
| “性能提升了 30%” | 相对什么基线、在哪种条件下、数据来自哪里 |
| “某篇论文证明了……” | 文献是否存在、实际结论与研究限制是什么 |
| “一定”“完全”“首次” | 原文是否使用同样强度的措辞、限定范围是什么 |
| 多个回答说法一致 | 是否只是重复同一来源，有没有独立证据 |

## 核验清单

- 回答有没有把计划、预期和已经发生的结果混在一起？
- 数字是否附有单位、基线和适用条件？
- 引用是否真实存在且支持相邻结论？
- 是否遗漏原文中的限制、例外和不确定性？
- 无法确认的内容是否仍明确标记为待核验？
