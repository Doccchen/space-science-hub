## 简要原则

从结论回到证据。平台提供的新闻出处、论文题录与检索线索，可以帮助你开始核验；显示来源不等于每条结论都已核实。

## 操作步骤

1. 打开新闻阅读页的“查看发布方原文”，核对标题、发布机构、发布时间与更新说明。
2. 找到支持结论的原始句子、表格或图注，保留上下文；核对数字、单位、试验条件与限定语。
3. 如果新闻引用论文，继续查找论文原文。核对标题、作者、年份和 DOI，再阅读相关方法、结果与局限。
4. 交叉核验时，优先寻找独立的一手资料。多家网站转载同一通稿，不能算多份独立证据。
5. 记录证据位置与访问日期。资料之间有冲突时，写明差异和未解决的问题。

## 新闻到论文的示例

假设一篇新闻称某种材料“更适合高温环境”，可以按下面的路径查证：

1. 在发布方原文找到相关表述及引用研究。
2. 在论文中核对测试温度、持续时间、对照材料与评价指标。
3. 判断研究条件是否足以支持你要写的应用场景。

只看到论文题名或摘要时，记录为“题录或摘要线索”，不要写成已经阅读全文。

## 核验记录模板

```text
待核验主张：
原始来源及链接：
作者或发布机构：
发布日期 / 访问日期：
证据位置（段落、页码、图表）：
关键原文与适用条件：
独立证据及差异：
结论：支持 / 部分支持 / 不支持 / 暂无法确认
```

## 核验清单

- 是否回到了发布方或研究者提供的原始资料？
- 链接与文献身份是否对应，证据位置是否可复查？
- 是否保留数字、单位、条件和限定语？
- 多个来源是否真正独立？
- 暂时无法访问的资料是否如实标记，避免声称已验证？
